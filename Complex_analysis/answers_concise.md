# Краткие ответы на экзаменационные вопросы по комплексному анализу

### 1. Комплексные числа. Определение, свойства, операции.
*   **Определение:** Комплексное число $z$ — это упорядоченная пара действительных чисел $(a, b)$, записывается как $z = a + ib$, где $i^2 = -1$. $a = \text{Re } z$, $b = \text{Im } z$.
*   **Операции:** Сложение и умножение выполняются по правилам операций над многочленами с учетом $i^2 = -1$.
*   **Сопряженное:** $\bar{z} = a - ib$.
*   **Модуль и аргумент:** $|z| = \sqrt{a^2 + b^2}$, $\text{arg } z = \varphi$, где $a = r\cos\varphi, b = r\sin\varphi$.
*   **Формы записи:** Алгебраическая ($a+ib$), тригонометрическая ($r(\cos\varphi + i\sin\varphi)$), показательная ($re^{i\varphi}$).

### 2. Сходимость последовательностей. Множества на плоскости. Непрерывные функции.
*   **Сходимость:** $z_n \to z_0$, если $|z_n - z_0| \to 0$. Эквивалентно сходимости $\text{Re } z_n \to \text{Re } z_0$ и $\text{Im } z_n \to \text{Im } z_0$.
*   **Множества:**
    *   *Область:* открытое связное множество.
    *   *Окрестность:* $\{z : |z - z_0| < \delta\}$.
    *   *Связность:* множество нельзя разбить на два непустых непересекающихся открытых подмножества.
*   **Непрерывность:** $f(z)$ непрерывна в $z_0$, если $\lim_{z \to z_0} f(z) = f(z_0)$.

### 3. Степенные ряды. Функциональные ряды.
*   **Функциональный ряд:** $\sum f_n(z)$. Сходится равномерно на $E$, если остаток $R_n(z) \to 0$ равномерно по $z \in E$.
*   **Признак Вейерштрасса:** Если $|f_n(z)| \le a_n$ и $\sum a_n < \infty$, то ряд сходится абсолютно и равномерно.
*   **Степенной ряд:** $\sum c_n(z-z_0)^n$. Сходится в круге $|z-z_0| < R$.

### 4. Теорема Коши-Адамара. Первая теорема Абеля.
*   **Теорема Коши-Адамара:** Радиус сходимости $R = 1/L$, где $L = \limsup_{n \to \infty} \sqrt[n]{|c_n|}$.
    *   Если $|z-z_0| < R$, ряд сходится абсолютно.
    *   Если $|z-z_0| > R$, ряд расходится.
*   **Первая теорема Абеля:** Если ряд сходится в точке $z^*$, то он абсолютно сходится во всем круге $|z-z_0| < |z^* - z_0|$.

### 5. Голоморфные (аналитические) функции. Условия Коши-Римана.
*   **Дифференцируемость:** $f(z)$ дифференцируема в $z$, если существует предел $f'(z) = \lim_{\Delta z \to 0} \frac{\Delta w}{\Delta z}$.
*   **Условия Коши-Римана:** Для $f = u + iv$ необходимо и (при дифференцируемости $u, v$ как функций двух переменных) достаточно:
    $$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$
*   **Аналитичность:** Дифференцируемость в каждой точке области.

### 6. Конформные отображения.
*   **Определение:** Отображение, сохраняющее углы между кривыми и обладающее постоянством растяжения в точке.
*   **Геометрический смысл:** Если $f(z)$ аналитична и $f'(z) \ne 0$, то отображение конформно.
    *   $|f'(z)|$ — коэффициент растяжения.
    *   $\text{arg } f'(z)$ — угол поворота.

### 7. Обратные функции. Римановы поверхности.
*   **Обратная функция:** Если $f(z)$ аналитична и $f'(z) \ne 0$, то локально существует аналитическая обратная функция $z = f^{-1}(w)$.
*   **Риманова поверхность:** Геометрическая конструкция для многозначных функций ($z^n, e^z$), позволяющая рассматривать их как однозначные на многолистной поверхности.
    *   Для $\sqrt[n]{z}$ — $n$ листов, склеенных в точках ветвления $0$ и $\infty$.
    *   Для $\text{Ln } z$ — бесконечно много листов.

### 8. Дробно-линейные отображения.
*   **Вид:** $w = \frac{az + b}{cz + d}$, $ad - bc \ne 0$.
*   **Свойства:**
    1.  Конформно на всей расширенной плоскости $\bar{\mathbb{C}}$.
    2.  *Круговое свойство:* переводит окружности и прямые в окружности и прямые.
    3.  *Сохранение симметрии:* симметричные точки переходят в симметричные.
    4.  Однозначно задается образами 3-х точек.

### 9. Комплексное интегрирование.
*   **Определение:** $\int_\Gamma f(z) dz = \int_\Gamma (u dx - v dy) + i \int_\Gamma (v dx + u dy)$.
*   **Свойства:** Линейность, аддитивность, $\int_{-\Gamma} = -\int_\Gamma$.
*   **Оценка:** $|\int_\Gamma f(z) dz| \le \max|f| \cdot \text{length}(\Gamma)$.

### 10. Лемма Гурса.
*   **Формулировка:** Если $f(z)$ аналитична в области $D$, то интеграл от $f(z)$ по границе любого прямоугольника (или треугольника) $\Delta \subset D$ равен нулю: $\oint_{\partial \Delta} f(z) dz = 0$.
*   **Значение:** Фундаментальный шаг в доказательстве интегральной теоремы Коши без требования непрерывности производной $f'(z)$.

### 11. Теорема Коши.
*   **Для односвязной области:** Если $f(z)$ аналитична в односвязной области $D$, то для любого замкнутого контура $\Gamma \subset D$: $\oint_\Gamma f(z) dz = 0$.
*   **Для многосвязной области:** Интеграл по внешней границе равен сумме интегралов по внутренним границам (в одном направлении обхода).
*   **Следствие:** Интеграл от аналитической функции не зависит от пути интегрирования.

### 12. Интебральная формула Коши.
*   **Формула:** $f(z) = \frac{1}{2\pi i} \oint_\Gamma \frac{f(\zeta)}{\zeta - z} d\zeta$.
*   **Значение:** Позволяет восстановить значения аналитической функции внутри области по её значениям на границе.
*   **Производные:** $f^{(n)}(z) = \frac{n!}{2\pi i} \oint_\Gamma \frac{f(\zeta)}{(\zeta - z)^{n+1}} d\zeta$. Аналитическая функция бесконечно дифференцируема.

### 13. Теорема Морера. Неопределенный интеграл.
*   **Теорема Морера:** Если $f(z)$ непрерывна в $D$ и $\oint_\Gamma f(z) dz = 0$ по любому замкнутому контуру, то $f(z)$ аналитична в $D$ (обращение теоремы Коши).
*   **Неопределенный интеграл:** $F(z) = \int_{z_0}^z f(\zeta) d\zeta$ является аналитической функцией и $F'(z) = f(z)$.

### 14. Ряд Тейлора.
*   **Теорема Тейлора:** Любая аналитическая в круге $|z-z_0| < R$ функция разлагается в степенной ряд: $f(z) = \sum_{n=0}^\infty c_n(z-z_0)^n$, где $c_n = \frac{f^{(n)}(z_0)}{n!}$.
*   Радиус сходимости $R$ равен расстоянию до ближайшей особой точки.

### 15. Теорема единственности. Нули функции.
*   **Нуль порядка $m$:** $f(z_0) = \dots = f^{(m-1)}(z_0) = 0, f^{(m)}(z_0) \ne 0$.
*   **Теорема единственности:** Если две аналитические в $D$ функции совпадают на множестве с предельной точкой внутри $D$, то они совпадают всюду в $D$. Нули аналитической функции (не равной 0) изолированы.

### 16. Неравенство Коши. Теорема Лиувилля.
*   **Неравенство Коши:** $|c_n| \le \frac{M(R)}{R^n}$, где $M(R) = \max_{|z-z_0|=R} |f(z)|$.
*   **Теорема Лиувилля:** Если целая функция (аналитична во всей $\mathbb{C}$) ограничена, то она есть константа.

### 17. Принцип максимума модуля.
*   Максимум модуля $|f(z)|$ аналитической функции, отличной от константы, достигается на границе области, а не внутри неё.
*   Если $|f(z)|$ достигает максимума внутри области, то $f(z) = \text{const}$.

### 18. Ряд Лорана.
*   **Теорема Лорана:** В кольце $r < |z-z_0| < R$ функция разлагается в ряд: $f(z) = \sum_{n=-\infty}^\infty c_n(z-z_0)^n$.
*   **Части:** $\sum_{n=0}^\infty \dots$ — *правильная*, $\sum_{n=-\infty}^{-1} \dots$ — *главная*.

### 19. Изолированные особые точки.
*   **Устранимая:** главная часть ряда Лорана равна 0. $\exists \lim_{z \to z_0} f(z) < \infty$.
*   **Полюс порядка $m$:** главная часть содержит конечное число членов ($c_{-m} \ne 0$). $\lim_{z \to z_0} f(z) = \infty$.
*   **Существенно особая:** главная часть содержит бесконечно много членов. Предела в точке не существует.

### 20. Теорема Сохоцкого-Вейерштрасса.
*   В любой окрестности существенно особой точки значения функции $f(z)$ подходят сколь угодно близко к любому комплексному числу $A \in \bar{\mathbb{C}}$.

### 21. Бесконечно удаленная особая точка.
*   Тип точки $z = \infty$ определяется через замену $\zeta = 1/z$ в точке $\zeta = 0$.
*   Разложение Лорана: $f(z) = \sum_{n=-\infty}^\infty c_n z^n$. *Главная часть* содержит положительные степени $z$.
*   $\infty$ — устранимая, если нет положительных степеней; полюс — если их конечное число; существенно особая — если бесконечно много.

### 22. Вычет аналитической функции.
*   **Определение:** $\text{res}_{z=z_0} f(z) = c_{-1}$ (коэффициент при $(z-z_0)^{-1}$ в ряду Лорана).
*   **Интегрально:** $\text{res}_{z=z_0} f(z) = \frac{1}{2\pi i} \oint_\gamma f(z) dz$.
*   **Вычет в $\infty$:** $\text{res}_{z=\infty} f(z) = -c_{-1}$ (в разложении по степеням $z$).

### 23. Основная теорема о вычетах.
*   Если $f(z)$ аналитична в $D$ за исключением точек $z_k$, то $\oint_{\partial D} f(z) dz = 2\pi i \sum \text{res}_{z=z_k} f(z)$.
*   Сумма всех вычетов на расширенной плоскости $\bar{\mathbb{C}}$ (включая $\infty$) равна 0.

### 24. Вычисление интегралов. Лемма Жордана.
*   Вычеты позволяют считать вещественные интегралы $\int_{-\infty}^\infty R(x) dx$ и $\int_0^{2\pi} R(\cos \theta, \sin \theta) d\theta$.
*   **Лемма Жордана:** дает условия, при которых интеграл по большой полуокружности в верхней полуплоскости $\int_{\Gamma_R} f(z) e^{iaz} dz \to 0$ при $R \to \infty$.

### 25. Принцип аргумента.
*   $\frac{1}{2\pi i} \oint_\Gamma \frac{f'(z)}{f(z)} dz = N - P$, где $N$ — число нулей, $P$ — число полюсов внутри $\Gamma$.
*   Геометрически: изменение аргумента $f(z)$ при обходе контура равно $2\pi(N-P)$.

### 26. Теорема Руше.
*   Если на контуре $\Gamma$ выполнено $|g(z)| < |f(z)|$, то функции $f(z)$ и $f(z) + g(z)$ имеют одинаковое количество нулей внутри $\Gamma$.
*   Применяется для доказательства основной теоремы алгебры.

### 27. Аналитическое продолжение.
*   Процесс расширения области задания аналитической функции.
*   Если две аналитические функции совпадают на подобласти, они являются продолжением друг друга (единственность).
*   Может приводить к многозначности (пример: $\text{Ln } z$).

### 28. Принцип непрерывности. Граничная теорема единственности.
*   **Принцип непрерывности:** Если функции из двух областей совпадают на общей дуге границы, они аналитически продолжаются друг в друга.
*   Если аналитическая функция равна 0 на дуге границы, то она $f(z) \equiv 0$.

### 29. Принцип симметрии Римана-Шварца.
*   Если $f(z)$ аналитична в $D^+$ и принимает вещественные значения на вещественной оси, её можно продолжить в $D^-$ по формуле $f(z) = \overline{f(\bar{z})}$.

### 30. Отображение двусвязных областей. Модуль.
*   Любая двусвязная область конформно отображается на кольцо $1 < |z| < M$.
*   Число $M$ называется *модулем* области и является конформным инвариантом (области с разными $M$ не эквивалентны).

### 31. Гармонические функции.
*   Удовлетворяют уравнению Лапласа $\Delta u = 0$.
*   $\text{Re } f(z)$ и $\text{Im } f(z)$ аналитической функции — гармонические (сопряженные).
*   **Свойства:** принцип максимума, теорема о среднем, бесконечная дифференцируемость.

### 32. Целые и мероморфные функции.
*   **Целые:** аналитичны во всей $\mathbb{C}$ (пример: $e^z, \sin z$). По Лиувиллю ограничены только константы.
*   **Мероморфные:** аналитичны в $\mathbb{C}$ за исключением полюсов (пример: $\text{tg } z$). На $\bar{\mathbb{C}}$ любая мероморфная функция — рациональная.
