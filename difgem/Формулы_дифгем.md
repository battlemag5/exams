# Шпаргалка: Формулы по дифференциальной геометрии
(собрано из задач)

## 1. Поверхности: Первая квадратичная форма
Пусть поверхность задана параметризацией $r(u, v)$.
Касательные векторы: 
$r_u = \frac{\partial r}{\partial u}, \quad r_v = \frac{\partial r}{\partial v}$

Коэффициенты первой квадратичной формы:
$E = \langle r_u, r_u \rangle$
$F = \langle r_u, r_v \rangle$
$G = \langle r_v, r_v \rangle$

Первая квадратичная форма (квадрат линейного элемента):
$ds^2 = E du^2 + 2F dudv + G dv^2$

## 2. Нормаль к поверхности
Единичный вектор нормали:
$n = \frac{r_u \times r_v}{|r_u \times r_v|}$
где $|r_u \times r_v| = \sqrt{EG - F^2}$.

## 3. Вторая квадратичная форма
Вторые производные радиус-вектора: $r_{uu}, r_{uv}, r_{vv}$.
Коэффициенты второй квадратичной формы:
$L = \langle r_{uu}, n \rangle$  (иногда обозначается как $e$)
$M = \langle r_{uv}, n \rangle$  (иногда обозначается как $f$)
$N = \langle r_{vv}, n \rangle$  (иногда обозначается как $g$)
*Альтернативная формула: $L = -\langle r_u, n_u \rangle, M = -\langle r_u, n_v \rangle = -\langle r_v, n_u \rangle, N = -\langle r_v, n_v \rangle$.*

Вторая квадратичная форма:
$II = L du^2 + 2M dudv + N dv^2$

## 4. Кривизны поверхности
**Гауссова кривизна:**
$K = \frac{LN - M^2}{EG - F^2}$

**Средняя кривизна:**
$H = \frac{EN - 2FM + GL}{2(EG - F^2)}$
*(В некоторых источниках без двойки в знаменателе, тогда это просто след оператора формы, но классически $H$ — полусумма)*

**Главные кривизны $k_1, k_2$:**
Являются корнями квадратного уравнения:
$k^2 - 2Hk + K = 0 \implies k_{1,2} = H \pm \sqrt{H^2 - K}$
Если $F=0$ и $M=0$, то координатные линии являются линиями кривизны, и $k_1 = \frac{L}{E}, k_2 = \frac{N}{G}$.

## 5. Геометрия на поверхности
**Угол $\theta$ между двумя кривыми $\gamma_1(t)$ и $\gamma_2(\tau)$:**
$\cos \theta = \frac{E \dot{u}_1 \dot{u}_2 + F(\dot{u}_1 \dot{v}_2 + \dot{u}_2 \dot{v}_1) + G \dot{v}_1 \dot{v}_2}{\sqrt{E \dot{u}_1^2 + 2F\dot{u}_1\dot{v}_1 + G\dot{v}_1^2} \sqrt{E \dot{u}_2^2 + 2F\dot{u}_2\dot{v}_2 + G\dot{v}_2^2}}$

**Символы Кристоффеля (при $F=0$):**
$\Gamma_{11}^1 = \frac{E_u}{2E}, \quad \Gamma_{11}^2 = -\frac{E_v}{2G}$
$\Gamma_{12}^1 = \frac{E_v}{2E}, \quad \Gamma_{12}^2 = \frac{G_u}{2G}$
$\Gamma_{22}^1 = -\frac{G_u}{2E}, \quad \Gamma_{22}^2 = \frac{G_v}{2G}$

**Уравнения геодезических:**
$\ddot{u} + \Gamma_{11}^1\dot{u}^2 + 2\Gamma_{12}^1\dot{u}\dot{v} + \Gamma_{22}^1\dot{v}^2 = 0$
$\ddot{v} + \Gamma_{11}^2\dot{u}^2 + 2\Gamma_{12}^2\dot{u}\dot{v} + \Gamma_{22}^2\dot{v}^2 = 0$

**Теорема Клеро для поверхностей вращения:**
$\rho(u) \cos \theta = c$
Где $\rho(u)$ — радиус вращения параллели, $\theta$ — угол между геодезической и параллелью, $c$ — константа вдоль геодезической.

**Теорема Гаусса-Бонне:**
$\iint_S K dA = 2\pi \chi(S)$ (для замкнутых компактных поверхностей)

## 6. Пространственные кривые
Пусть кривая задана параметризацией $r(t)$.

**Длина дуги:**
$L = \int_{t_1}^{t_2} |\dot{r}(t)| dt = \int_{t_1}^{t_2} \sqrt{\dot{x}^2 + \dot{y}^2 + \dot{z}^2} dt$
(В полярных координатах $\rho = \rho(\phi)$: $L = \int \sqrt{\rho^2 + (\rho')^2} d\phi$)

**Репер Френе (произвольный параметр $t$):**
1. Касательный вектор: $\tau = \frac{\dot{r}}{|\dot{r}|}$
2. Бинормаль: $\beta = \frac{\dot{r} \times \ddot{r}}{|\dot{r} \times \ddot{r}|}$
3. Главная нормаль: $\nu = \beta \times \tau$

**Кривизна и кручение (произвольный параметр $t$):**
Кривизна: $k = \frac{|\dot{r} \times \ddot{r}|}{|\dot{r}|^3}$
Кручение: $\kappa = \frac{\langle \dot{r}, \ddot{r}, \dddot{r} \rangle}{|\dot{r} \times \ddot{r}|^2}$ (смешанное произведение в числителе)

**Формулы Френе (для натурального параметра $s$):**
При $|\dot{r}| = 1$:
$\dot{\tau} = k \cdot \nu$
$\dot{\nu} = -k \cdot \tau + \kappa \cdot \beta$
$\dot{\beta} = -\kappa \cdot \nu$
*(где точкой обозначается дифференцирование по $s$)*

## 7. Теорема Менье и нормальная кривизна
Для кривой на поверхности с нормалью $N$:
Вектор ускорения (в натуральной параметризации) раскладывается как:
$\ddot{\gamma} = k_g (\vec{N} \times \dot{\gamma}) + k_n \vec{N}$
Где $k_n$ — нормальная кривизна кривой на поверхности (зависит только от направления), $k_g$ — геодезическая кривизна.
