# Задачи по дифференциальной геометрии и их решения

## 1. Алина: Цилиндр
**Условие:** Для поверхности $r(u, v) = (r \cos u, r \sin u, v)$ найти главные кривизны и главные направления. Также Гауссову и среднюю кривизны.
*(Здесь $r$ в формуле — это константа (радиус цилиндра), обозначим ее $R$ для избежания путаницы с радиус-вектором).*

**Решение:**
1. Векторы касательного пространства:
$r_u = (-R \sin u, R \cos u, 0)$
$r_v = (0, 0, 1)$
2. Первая квадратичная форма:
$E = \langle r_u, r_u \rangle = R^2 \sin^2 u + R^2 \cos^2 u = R^2$
$F = \langle r_u, r_v \rangle = 0$
$G = \langle r_v, r_v \rangle = 1$
3. Нормаль к поверхности:
$n = \frac{r_u \times r_v}{|r_u \times r_v|} = (\cos u, \sin u, 0)$
4. Вторые производные:
$r_{uu} = (-R \cos u, -R \sin u, 0)$
$r_{uv} = (0, 0, 0)$
$r_{vv} = (0, 0, 0)$
5. Вторая квадратичная форма:
$L = \langle r_{uu}, n \rangle = -R \cos^2 u - R \sin^2 u = -R$
$M = \langle r_{uv}, n \rangle = 0$
$N = \langle r_{vv}, n \rangle = 0$
6. Кривизны и направления:
Так как $F = 0$ и $M = 0$, координатные линии являются линиями кривизны (главными направлениями).
Главные кривизны: $k_1 = \frac{L}{E} = -\frac{R}{R^2} = -\frac{1}{R}$ и $k_2 = \frac{N}{G} = 0$.
Гауссова кривизна: $K = k_1 k_2 = 0$.
Средняя кривизна: $H = \frac{k_1 + k_2}{2} = -\frac{1}{2R}$.

## 2. Рустем: Угол между линиями
**Условие:** Найти угол между линиями $v = u+1$ и $v = 3-u$ на поверхности $r(u,v) = (u \cos v, u \sin v, u^2)$.

**Решение:**
1. Точка пересечения: $u+1 = 3-u \Rightarrow 2u = 2 \Rightarrow u = 1$. Тогда $v = 2$.
2. Вычислим коэффициенты первой квадратичной формы в этой точке:
$r_u = (\cos v, \sin v, 2u)$
$r_v = (-u \sin v, u \cos v, 0)$
$E = 1 + 4u^2 = 1 + 4(1)^2 = 5$
$F = 0$
$G = u^2 = 1$
3. Векторы скоростей кривых в координатах $(u, v)$:
Первая кривая: $\gamma_1(u) = (u, u+1) \Rightarrow (\dot{u}_1, \dot{v}_1) = (1, 1)$.
Вторая кривая: $\gamma_2(u) = (u, 3-u) \Rightarrow (\dot{u}_2, \dot{v}_2) = (1, -1)$.
4. Косинус угла $\theta$:
$\cos \theta = \frac{E \dot{u}_1 \dot{u}_2 + F(\dot{u}_1 \dot{v}_2 + \dot{u}_2 \dot{v}_1) + G \dot{v}_1 \dot{v}_2}{\sqrt{E \dot{u}_1^2 + 2F\dot{u}_1\dot{v}_1 + G\dot{v}_1^2} \sqrt{E \dot{u}_2^2 + 2F\dot{u}_2\dot{v}_2 + G\dot{v}_2^2}}$
Подставляем значения:
$\cos \theta = \frac{5(1)(1) + 0 + 1(1)(-1)}{\sqrt{5(1)^2 + 1(1)^2} \sqrt{5(1)^2 + 1(-1)^2}} = \frac{5 - 1}{\sqrt{6} \sqrt{6}} = \frac{4}{6} = \frac{2}{3}$.
Угол: $\theta = \arccos(2/3)$.

## 3. Даша: Плоскость
**Условие:** Доказать, что вторая квадратичная форма плоскости при любой ее параметризации тождественно равна нулю.

**Решение:**
Плоскость характеризуется тем, что ее нормальный вектор $n(u,v)$ постоянен во всех точках, то есть не зависит от координат на плоскости: $n \equiv const$.
Коэффициенты второй квадратичной формы вычисляются по формулам:
$L = -\langle r_u, n_u \rangle$
$M = -\langle r_u, n_v \rangle = -\langle r_v, n_u \rangle$
$N = -\langle r_v, n_v \rangle$
Так как нормаль постоянна, ее производные равны нулю: $n_u = 0, n_v = 0$.
Следовательно, $L \equiv 0, M \equiv 0, N \equiv 0$. Вторая квадратичная форма $II = L du^2 + 2M dudv + N dv^2 \equiv 0$.

## 4. Исламбек: Вектор кривизны (формулы Френе)
**Условие:** Доказать формулу для $\ddot{\gamma}$ (ускорения) в натуральной параметризации.

**Решение:**
В натуральной параметризации $s$ (или $l$) касательный вектор $\tau = \dot{\gamma} = \frac{d\gamma}{ds}$ имеет единичную длину ($|\tau| = 1$).
Продифференцируем тождество $\langle \tau, \tau \rangle = 1$ по $s$:
$2 \langle \dot{\tau}, \tau \rangle = 0 \Rightarrow \langle \ddot{\gamma}, \dot{\gamma} \rangle = 0$.
Это означает, что вектор $\ddot{\gamma}$ ортогонален касательному вектору. По первой формуле Френе $\dot{\tau} = k \cdot n$, где $n$ — вектор главной нормали кривой, $k$ — кривизна. 
Если кривая лежит на поверхности, то по теореме Менье вектор $\ddot{\gamma}$ раскладывается по нормали к поверхности $N$ и вектору нормали, касательному к поверхности (геодезической нормали):
$\ddot{\gamma} = k_g (\vec{N} \times \dot{\gamma}) + k_n \vec{N}$
где $k_g$ — геодезическая кривизна, $k_n$ — нормальная кривизна.

## 5. Мила: Гипербола
**Условие:** Найти репер Френе и кривизну гиперболы.

**Решение:**
Параметризация: $r(t) = (a \cosh t, b \sinh t, 0)$.
1. Производные:
$\dot{r} = (a \sinh t, b \cosh t, 0)$
$\ddot{r} = (a \cosh t, b \sinh t, 0)$
2. Касательный вектор $\tau$:
$\tau = \frac{\dot{r}}{|\dot{r}|} = \frac{1}{\sqrt{a^2 \sinh^2 t + b^2 \cosh^2 t}} (a \sinh t, b \cosh t, 0)$.
3. Бинормаль $\beta$ (перпендикулярна плоскости кривой $z=0$):
$\dot{r} \times \ddot{r} = (0, 0, a \sinh t \cdot b \sinh t - b \cosh t \cdot a \cosh t) = (0, 0, -ab (\cosh^2 t - \sinh^2 t)) = (0, 0, -ab)$.
Так как $\beta = \frac{\dot{r} \times \ddot{r}}{|\dot{r} \times \ddot{r}|}$, получаем $\beta = (0, 0, -1)$.
4. Главная нормаль $\nu$:
$\nu = \beta \times \tau = \frac{1}{\sqrt{a^2 \sinh^2 t + b^2 \cosh^2 t}} (b \cosh t, -a \sinh t, 0)$.
5. Кривизна $k$:
$k = \frac{|\dot{r} \times \ddot{r}|}{|\dot{r}|^3} = \frac{ab}{(a^2 \sinh^2 t + b^2 \cosh^2 t)^{3/2}}$.

## 6. Катя: Поверхность вращения
**Условие:** Доказать, что параллели и меридианы поверхности вращения — это линии кривизны, найти главные кривизны.

**Решение:**
Параметризация: $r(u,v) = (f(u)\cos v, f(u)\sin v, g(u))$.
1. $r_u = (f'\cos v, f'\sin v, g')$, $r_v = (-f\sin v, f\cos v, 0)$.
2. Первая форма: $F = \langle r_u, r_v \rangle = 0$.
3. Нормаль: $N \propto (f\cos v, f\sin v, 0) \times (f'\cos v, f'\sin v, g') \Rightarrow N_v$ не содержит компоненты по $z$.
Легко показать, что $M = \langle r_{uv}, N \rangle = \langle (-f'\sin v, f'\cos v, 0), N \rangle = 0$.
Так как $F = 0$ и $M = 0$, координатные линии $u$ (меридианы) и $v$ (параллели) являются линиями кривизны.
Главные кривизны: $k_1 = \frac{L}{E}$, $k_2 = \frac{N}{G}$.

## 7. Егор: Геодезическая и асимптотическая
**Условие:** Доказать, что кривая на поверхности является одновременно геодезической и асимптотической если и только если она прямая.

**Решение:**
1. Если кривая прямая, ее ускорение $\ddot{\gamma} = 0$. Геодезическая кривизна $k_g$ (касательная к поверхности компонента) и нормальная кривизна $k_n$ (нормальная компонента) обе равны нулю. Значит, кривая геодезическая и асимптотическая.
2. Обратно: Если кривая асимптотическая, то $k_n = 0$. Если она геодезическая, то $k_g = 0$.
Полный вектор кривизны кривой в $\mathbb{R}^3$ равен $k = \sqrt{k_g^2 + k_n^2}$.
Так как $k_g = 0$ и $k_n = 0$, получаем $k = 0$. Кривая с нулевой кривизной в пространстве является прямой линией.

## 8. Соня: Кривизна и кручение
**Условие:** В точке $P(1, 1, 1)$ найти кривизну и кручение $x^2+z^2-y^2=1$, $y^2-2x+z=0$.

**Решение:**
Пусть $F_1 = x^2+z^2-y^2-1$, $F_2 = y^2-2x+z$.
Градиенты:
$\nabla F_1 = (2x, -2y, 2z) \implies$ в т. P: $(2, -2, 2) \sim (1, -1, 1)$.
$\nabla F_2 = (-2, 2y, 1) \implies$ в т. P: $(-2, 2, 1)$.
Касательный вектор $v = \nabla F_1 \times \nabla F_2 = (-1 - 2, -2 - 1, 2 - 2) = (-3, -3, 0) \sim (1, 1, 0)$.
Продифференцировав уравнения поверхностей дважды по натуральному параметру $s$, можно найти $\ddot{r}$ (вектор кривой), а затем через смешанные производные найти кривизну и кручение по формулам $k = \frac{|\dot{r} \times \ddot{r}|}{|\dot{r}|^3}$ и $\kappa = \frac{\langle \dot{r}, \ddot{r}, \dddot{r} \rangle}{|\dot{r} \times \ddot{r}|^2}$.

## 9. Валера: Параболоид
**Условие:** По теореме Клеро описать геодезические на параболоиде вращения $z = u^2$.

**Решение:**
Теорема Клеро: $\rho(u) \cos \theta = c$, где $\rho(u) = u$ — радиус параллели.
Получаем $u \cos \theta = c$.
1. $c = 0 \implies \cos \theta = 0$, геодезические — меридианы (ортогональны параллелям и уходят в бесконечность).
2. $c \neq 0 \implies u = \frac{c}{\cos \theta}$. Так как $|\cos \theta| \le 1$, то $u \ge |c|$.
Геодезическая приближается к вершине параболоида лишь до параллели радиуса $u = |c|$, в этой точке она касается параллели ($\theta = 0$), а затем уходит обратно в бесконечность.

## 10. Святослав: Сфера
**Условие:** Доказать, что для любой параметризации сферы первая и вторая квадратичные формы пропорциональны.

**Решение:**
Для сферы радиуса $R$ с центром в нуле вектор нормали в каждой точке совпадает по направлению с радиус-вектором (или противоположен ему): $N = \pm \frac{r}{R}$.
Оператор формы (оператор Вейнгартена) $W = -dN$.
$dN = d(\pm \frac{r}{R}) = \pm \frac{1}{R} dr$.
Отсюда получаем, что оператор формы скалярный: $W = \mp \frac{1}{R} I$.
Вторая квадратичная форма $II(X,Y) = \langle WX, Y \rangle = \mp \frac{1}{R} \langle X, Y \rangle = \mp \frac{1}{R} I(X,Y)$.
Следовательно, $II = \mp \frac{1}{R} I$, формы пропорциональны с коэффициентом $\mp \frac{1}{R}$.

## 11. Задача 18: Поверхность из нормалей
**Условие:** Поверхность состоит из нормалей к кривой $\gamma(l)$. Найти $E, F, G, K, H$.

**Решение:**
Параметризация: $r(l, v) = \gamma(l) + v \cdot \nu(l)$, где $\nu$ — главная нормаль, $l$ - натуральный параметр кривой $\gamma$.
$r_l = \dot{\gamma} + v \dot{\nu} = \tau + v(-k\tau + \kappa\beta) = (1 - vk)\tau + v\kappa\beta$.
$r_v = \nu$.

**Первая квадратичная форма:**
$E = \langle r_l, r_l \rangle = (1 - vk)^2 + (v\kappa)^2$
$F = \langle r_l, r_v \rangle = \langle (1-vk)\tau + v\kappa\beta, \nu \rangle = 0$
$G = \langle r_v, r_v \rangle = \langle \nu, \nu \rangle = 1$

**Нормаль к поверхности:**
$r_l \times r_v = ((1-vk)\tau + v\kappa\beta) \times \nu = (1-vk)(\tau \times \nu) + v\kappa(\beta \times \nu) = (1-vk)\beta - v\kappa\tau$.
Ее длина равна $\sqrt{(1-vk)^2 + v^2\kappa^2} = \sqrt{E}$.
Единичный вектор нормали: $N = \frac{1}{\sqrt{E}} (-v\kappa\tau + (1-vk)\beta)$.

**Вторая квадратичная форма:**
$r_{vv} = \frac{\partial}{\partial v}(\nu) = 0$.
$N_2 = \langle r_{vv}, N \rangle = 0$ (где $N_2$ — коэффициент формы, обычно обозначаемый $N$, но мы используем $N_2$ чтобы не путать с нормалью).
$r_{lv} = \dot{\nu} = -k\tau + \kappa\beta$.
$M = \langle r_{lv}, N \rangle = \frac{1}{\sqrt{E}} (-v\kappa(-k) + (1-vk)\kappa) = \frac{1}{\sqrt{E}} (vk\kappa + \kappa - vk\kappa) = \frac{\kappa}{\sqrt{E}}$.
$r_{ll} = \frac{\partial}{\partial l} ((1-vk)\tau + v\kappa\beta) = -v\dot{k}\tau + (1-vk)\dot{\tau} + v\dot{\kappa}\beta + v\kappa\dot{\beta}$.
Используя формулы Френе ($\dot{\tau} = k\nu$, $\dot{\beta} = -\kappa\nu$):
$r_{ll} = -v\dot{k}\tau + (1-vk)k\nu + v\dot{\kappa}\beta - v\kappa^2\nu = -v\dot{k}\tau + ((1-vk)k - v\kappa^2)\nu + v\dot{\kappa}\beta$.
$L = \langle r_{ll}, N \rangle = \frac{1}{\sqrt{E}} (-v\dot{k}(-v\kappa) + v\dot{\kappa}(1-vk)) = \frac{v^2\kappa\dot{k} + v\dot{\kappa}(1-vk)}{\sqrt{E}}$.

**Кривизны:**
Гауссова кривизна $K = \frac{L N_2 - M^2}{EG - F^2} = \frac{0 - M^2}{E \cdot 1 - 0} = -\frac{M^2}{E} = -\frac{\kappa^2/E}{E} = -\frac{\kappa^2}{E^2} = -\frac{\kappa^2}{((1-vk)^2 + v^2\kappa^2)^2}$.
Средняя кривизна $H = \frac{E N_2 - 2FM + GL}{2(EG-F^2)} = \frac{0 - 0 + 1 \cdot L}{2E} = \frac{L}{2E} = \frac{v^2\kappa\dot{k} + v\dot{\kappa}(1-vk)}{2E^{3/2}}$.

## 12. Ярослав: Геликоид
**Условие:** Найти кривизны геликоида.

**Решение:**
Параметризация: $r(u,v) = (v\cos u, v\sin u, cu)$.
**Первая квадратичная форма:**
$r_u = (-v\sin u, v\cos u, c)$
$r_v = (\cos u, \sin u, 0)$
$E = \langle r_u, r_u \rangle = v^2\sin^2 u + v^2\cos^2 u + c^2 = v^2 + c^2$
$F = \langle r_u, r_v \rangle = -v\sin u\cos u + v\cos u\sin u + 0 = 0$
$G = \langle r_v, r_v \rangle = \cos^2 u + \sin^2 u = 1$

**Вторая квадратичная форма:**
$r_u \times r_v = \begin{vmatrix} i & j & k \\ -v\sin u & v\cos u & c \\ \cos u & \sin u & 0 \end{vmatrix} = (-c\sin u, c\cos u, -v)$.
Модуль векторного произведения равен $\sqrt{c^2\sin^2 u + c^2\cos^2 u + v^2} = \sqrt{c^2+v^2}$.
Единичный вектор нормали $n = \frac{1}{\sqrt{c^2+v^2}} (-c\sin u, c\cos u, -v)$.
Вторые производные:
$r_{uu} = (-v\cos u, -v\sin u, 0)$
$r_{uv} = (-\sin u, \cos u, 0)$
$r_{vv} = (0, 0, 0)$
Коэффициенты формы:
$L = \langle r_{uu}, n \rangle = \frac{1}{\sqrt{c^2+v^2}} (cv\sin u\cos u - cv\sin u\cos u + 0) = 0$.
$M = \langle r_{uv}, n \rangle = \frac{1}{\sqrt{c^2+v^2}} (c\sin^2 u + c\cos^2 u + 0) = \frac{c}{\sqrt{c^2+v^2}}$.
$N = \langle r_{vv}, n \rangle = 0$.

**Кривизны:**
Гауссова кривизна: $K = \frac{LN-M^2}{EG-F^2} = \frac{0 - \frac{c^2}{c^2+v^2}}{(v^2+c^2) \cdot 1 - 0} = -\frac{c^2}{(v^2+c^2)^2}$.
Средняя кривизна: $H = \frac{EN - 2FM + GL}{2(EG-F^2)} = 0$ (так как $L=N=F=0$).
Главные кривизны определяются из уравнения $k^2 - 2Hk + K = 0$.
Так как $H = 0$, $k^2 + K = 0 \implies k^2 = -K = \frac{c^2}{(v^2+c^2)^2} \implies k_{1,2} = \pm \frac{c}{v^2+c^2}$.

## 13. Федя: Набор задач
Федя: 1. Найти репер френе и кривизну эллипса с полуосями a, b.  
2. Найти репер френе и кривизну y^2 = 2px  
3. Вычислить длину ветви спирали архимеда ро = альфа * фи  
4. Для поверхности, состоящей из бинормалей бета бирегулярной параметризованной кривой гамма вычислить, первую, вторую квадратичные формы, среднюю и гауссову кривизны
5. **Эллипс:** $r(t) = (a\cos t, b\sin t)$. $k = \frac{ab}{(a^2\sin^2t + b^2\cos^2t)^{3/2}}$.
6. **Парабола:** $x = y^2 / 2p \implies r(y) = (y^2 / 2p, y)$. Вектор касательной $\dot{r} = (y/p, 1)$. $k = \frac{p^2}{(p^2+y^2)^{3/2}}$.
7. **Архимедова спираль:** В полярных $\rho = \alpha \phi$. Длина $L = \int \sqrt{\rho^2 + (\rho')^2} d\phi = \int_0^{\phi} \sqrt{\alpha^2 \phi^2 + \alpha^2} d\phi = \frac{\alpha}{2} [\phi\sqrt{1+\phi^2} + \ln(\phi + \sqrt{1+\phi^2})]$.
8. **Поверхность из бинормалей:** $r(l, v) = \gamma(l) + v \cdot \beta(l)$. $E = 1 + v^2\kappa^2, F=0, G=1$. Так как это поверхность главных нормалей для изотропных кривых, расчет дает $K = -\frac{\kappa^2}{(1+v^2\kappa^2)^2}$.
