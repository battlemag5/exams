**1. Формулировка т. Пикара**
Если функция $f(t,y)$ непрерывна в цилиндрической области и удовлетворяет там условию Липшица по $y$, то существует единственное решение задачи Коши $y' = f(t,y)$, $y(t_0) = y^0$ на локальном отрезке $|t - t_0| \le T_0$. 

**2. Уметь ставить задачу Коши**
Постановка задачи Коши для системы дифференциальных уравнений заключается в задании самого уравнения (или системы) $y' = f(t,y)$ и начального условия $y(t_0) = y^0$. Для уравнения $n$-го порядка задается значение функции и ее производных до $(n-1)$-го порядка включительно: $u(t_0)=u_0, u'(t_0)=u_1, \dots, u^{(n-1)}(t_0)=u_{n-1}$.

**3. Метод вариации произвольной постоянной (и для систем и для уравнений?)**
Для систем $y' = A(t)y + h(t)$ общее решение однородной системы записывается как $Y(t)C$, где $Y(t)$ — фундаментальная матрица. Для неоднородной системы решение ищется в виде $Y(t)C(t)$. После подстановки в уравнение получаем $Y(t)C'(t) = h(t)$, откуда $C(t)$ находится интегрированием. Аналогично работает и для линейных уравнений $n$-го порядка, так как они сводятся к системам первого порядка.

**4. Определение непродолжаемого решения**
Решение называется непродолжаемым, если оно не имеет продолжения (не может быть доопределено как решение) ни влево, ни вправо от своего интервала существования. Непродолжаемое решение обязательно покидает любой компакт, лежащий внутри области определения правой части.

**5. Функция Ляпунова**
Функцией Ляпунова $H(y)$ называется непрерывно дифференцируемая скалярная функция, которая положительно определена (т.е. $H(y) \ge 0$ и $H(y)=0 \iff y=0$), а ее полная производная в силу системы неположительна $\langle \nabla H(y), f(y) \rangle \le 0$. Она используется для доказательства устойчивости (если производная $\le 0$), асимптотической устойчивости (если производная $< 0$ вне нуля) и продолжимости решений на полуось.

**6. ФСР для систем линейных ДУ, ФМП для систем**
Набор из $n$ линейно независимых решений однородной системы $y'=A(t)y$ называется фундаментальной системой решений (ФСР). Матрица $Y(t)$, столбцами которой являются эти решения, называется фундаментальной матрицей решений (ФМР). Любое решение представимо в виде $y(t) = Y(t)C$.

**7. ФСР, ФМР для линейных уравнений высокого порядка**
Любые $n$ линейно независимых решений однородного уравнения $n$-го порядка образуют ФСР. Матрица $U(t)$, составленная из этих решений и их производных до $(n-1)$-го порядка, является фундаментальной (и называется матрицей Вронского).

**8. Способы вычисления матричной экспоненты ($e^{tA}$)**
1. **Через жорданову форму:** $A = TJT^{-1} \implies e^{tA} = Te^{tJ}T^{-1}$, где экспонента от жордановой клетки выписывается явно.
2. **Через $\psi$-функции:** Как полином от матрицы: $e^{tA} = \psi(t,\tau_1)I + \psi(t,\tau_1,\tau_2)(A-\tau_1 I) + \dots$, где $\tau_i$ — собственные значения. Этот способ не требует поиска собственных векторов.

**9. Пси-функции (определения и свойства)**
Это специальные функции $\psi(t, \tau_1, \dots, \tau_k)$, определяющие ФСР уравнения с постоянными коэффициентами. Свойства: непрерывны, симметричны по $\tau_i$, вектор из них является решением спец. задачи Коши. При совпадающих корнях $\psi = \frac{t^{k-1}}{(k-1)!}e^{\tau t}$, при различных — это линейная комбинация экспонент.

**10. Постановка краевой задачи для систем на всей прямой**
Ищется решение системы $y' = Ay + f(t)$, ограниченное на всей числовой прямой $\mathbb{R}$ ($\sup \|y(t)\| < \infty$). Если матрица $A$ не имеет собственных значений на мнимой оси (дихотомия), задача имеет единственное решение для любой ограниченной $f(t)$.

**11. Постановка краевой задачи для уравнения высокого порядка на всей прямой**
Ищется решение $P_n(d/dt)u = \varphi(t)$, ограниченное на $\mathbb{R}$. Если характеристический полином не имеет корней на мнимой оси, то задача имеет единственное ограниченное решение, выражаемое через функцию Грина.

**12. Постановка на отрезке для систем**
Решается $y' = A(t)y + f(t)$ на интервале $a < t < b$ с краевыми условиями $L y|_{t=a} + R y|_{t=b} = \varphi$. Задача однозначно разрешима при условии $\det(LY(a) + RY(b)) \ne 0$.

**13. Постановка краевой задачи на полупрямой (системы, уравнения)**
Ищется ограниченное при $t > 0$ решение с заданным краевым условием в нуле (например $B y|_{t=0} = \varphi$). Однозначно разрешима при выполнении *условия Лопатинского*: для системы — $\det B(v_1 \dots v_\mu) \ne 0$ (где $v_i$ — базис левой полуплоскости), для уравнений $n$-го порядка — независимость краевых полиномов $b_j(\tau)$ по модулю $P^-(\tau)$ (корней из левой полуплоскости).

**14. Постановка на отрезке для уравнений высокого порядка**
Уравнение $n$-го порядка решается на $a < t < b$ с краевыми условиями вида $L U(a) + R U(b) = \psi$, где $U$ содержит функцию и её производные. Разрешимость требует $\Delta = \det(LY(a) + RY(b)) \ne 0$.

**15. Задача Штурма-Лиувилля: что это?**
Это задача о нахождении нетривиальных решений (собственных функций) и параметра $\lambda$ (собственных значений) для краевой задачи вида $u'' + q(t)u = \lambda u$ с краевыми условиями на концах отрезка. Все $\lambda$ вещественны и образуют убывающую к $-\infty$ последовательность, а собственные функции ортогональны.

**16. Определения устойчивости по Ляпунову**
Решение $\bar{y}(t)$ устойчиво, если для любого $\varepsilon > 0$ существует $\delta > 0$ такое, что при начальном отклонении $\|y(t_0) - \bar{y}(t_0)\| < \delta$, отклонение решений $\|y(t) - \bar{y}(t)\| < \varepsilon$ сохраняется для всех $t \ge t_0$.

**17. Определение асимптотической устойчивости**
Решение асимптотически устойчиво, если оно устойчиво по Ляпунову и дополнительно существует $\delta_0 > 0$, при котором $\|y(t_0) - \bar{y}(t_0)\| < \delta_0 \implies \|y(t) - \bar{y}(t)\| \to 0$ при $t \to \infty$.

**18. Неустойчивость**
Отсутствие устойчивости по Ляпунову. Возникает, например, когда в линейной системе есть собственное значение с $\text{Re}\lambda > 0$, или когда существует функция Четаева (ее производная строго положительна в некоторой области).

**19. Определение матрицы монодромии, мультипликаторы**
Для систем с периодическими коэффициентами $A(t+T)=A(t)$, матрица монодромии $B$ связывает ФМР на периоде: $Y(t+T) \equiv Y(t)B$. Ее собственные значения называются *мультипликаторами* $\mu$. Для асимптотической устойчивости нужно, чтобы все $|\mu| < 1$.

**20. Первые интегралы (определение)**
Функция $\Phi(t,y) \not\equiv \text{const}$ называется первым интегралом системы, если вдоль любой её фазовой траектории она сохраняет постоянное значение: $\Phi(t,y(t)) \equiv \text{const}$. Если функция гладкая, то $\frac{\partial\Phi}{\partial t} + \sum f_j \frac{\partial\Phi}{\partial y_j} = 0$.

**21. Задача Коши для уравнений с частными производными 1-го порядка (постановка)**
Уравнение вида $f_0 u_t + \sum_{j=1}^n f_j u_{y_j} = g$. Задача Коши: найти решение, удовлетворяющее начальному условию $u|_{t=t_0} = \varphi(y)$. Решается методом сведения к поиску первых интегралов соответствующей системы ОДУ (характеристик).

**22. Что такое характеристики для уравнений с частными производными 1-порядка?**
Это фазовые траектории (кривые) автономной системы обыкновенных дифференциальных уравнений $\frac{dt}{ds} = f_0$, $\frac{dy_j}{ds} = f_j$. Вдоль этих кривых решение линейного однородного уравнения с частными производными сохраняет постоянное значение.
