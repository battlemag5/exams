**1. Формулировка т. Пикара**
Если функция $f(t,y)$ непрерывна в цилиндрической области и удовлетворяет там условию Липшица по $y$, то существует единственное решение задачи Коши $y' = f(t,y)$, $y(t_0) = y^0$ на локальном отрезке $|t - t_0| \le T_0$. 

**2. Уметь ставить задачу Коши**
Постановка задачи Коши для системы дифференциальных уравнений заключается в задании самого уравнения (или системы) $y' = f(t,y)$ и начального условия $y(t_0) = y^0$. Для уравнения $n$-го порядка задается значение функции и ее производных до $(n-1)$-го порядка включительно: $u(t_0)=u_0, u'(t_0)=u_1, \dots, u^{(n-1)}(t_0)=u_{n-1}$.

**3. Метод вариации произвольной постоянной (и для систем и для уравнений?)**
Для систем $y' = A(t)y + h(t)$ общее решение однородной системы записывается как $Y(t)C$, где $Y(t)$ — фундаментальная матрица. Для неоднородной системы решение ищется в виде $Y(t)C(t)$. После подстановки в уравнение получаем $Y(t)C'(t) = h(t)$, откуда $C(t)$ находится интегрированием. Аналогично работает и для линейных уравнений $n$-го порядка, так как они сводятся к системам первого порядка.

**Пример метода вариации произвольной постоянной:**
Решим неоднородное линейное уравнение 1-го порядка: $y' - \frac{1}{t}y = t$
1. Решаем однородное уравнение: $y' - \frac{1}{t}y = 0 \implies \frac{dy}{y} = \frac{dt}{t} \implies \ln|y| = \ln|t| + \ln|C| \implies y_{одн} = C \cdot t$.
2. Вариация постоянной: предполагаем $y(t) = C(t) \cdot t$.
3. Подстановка: $(C'(t)t + C(t)) - \frac{1}{t}(C(t)t) = t \implies C'(t)t = t \implies C'(t) = 1$.
4. Находим $C(t)$: $C(t) = t + C_1$. 
Общее решение: $y(t) = (t + C_1) \cdot t = t^2 + C_1 t$.

**4. Определение непродолжаемого решения**
Решение называется непродолжаемым, если оно не имеет продолжения (не может быть доопределено как решение) ни влево, ни вправо от своего интервала существования. Непродолжаемое решение обязательно покидает любой компакт, лежащий внутри области определения правой части.

**Пример непродолжаемого решения:**
Рассмотрим задачу Коши $y' = y^2, \quad y(0) = 1$.
Интегрируем: $\frac{dy}{y^2} = dt \implies -\frac{1}{y} = t + C$. Из начального условия $C = -1$, откуда $y(t) = \frac{1}{1 - t}$.
Это решение определено только на интервале $t \in (-\infty, 1)$. При $t \to 1$ функция уходит в бесконечность, и ее невозможно продолжить вправо за $t=1$. Таким образом, оно является непродолжаемым.

**5. Функция Ляпунова**
Функцией Ляпунова $H(y)$ называется непрерывно дифференцируемая скалярная функция, которая положительно определена (т.е. $H(y) \ge 0$ и $H(y)=0 \iff y=0$), а ее полная производная в силу системы неположительна $\langle \nabla H(y), f(y) \rangle \le 0$. Она используется для доказательства устойчивости (если производная $\le 0$), асимптотической устойчивости (если производная $< 0$ вне нуля) и продолжимости решений на полуось.

**Как пользоваться функцией Ляпунова:**
1. **Выбрать функцию $H(y)$.** Обычно ее ищут в виде положительно определенной квадратичной формы, например $H(y_1, y_2) = a y_1^2 + b y_2^2$ (в физических задачах это часто полная энергия).
2. **Вычислить производную в силу системы.** Найти $\frac{dH}{dt}$, подставив вместо производных правые части системы $\dot{y}_i = f_i(y)$:
   $$ \frac{dH}{dt} = \sum_i \frac{\partial H}{\partial y_i} \dot{y}_i = \sum_i \frac{\partial H}{\partial y_i} f_i(y) $$
3. **Исследовать знак $\frac{dH}{dt}$ в окрестности нуля:**
   * Если $\frac{dH}{dt} \le 0$ (отрицательно полуопределена), то нулевое решение **устойчиво**.
   * Если $\frac{dH}{dt} < 0$ при $y \neq 0$ (строго отрицательно определена), то решение **асимптотически устойчиво**.
   * Если найдется область, где $H > 0$ и $\frac{dH}{dt} > 0$, то нулевое решение **неустойчиво** (по теореме Четаева/Ляпунова о неустойчивости).

**6. ФСР для систем линейных ДУ, ФМР для систем**
Набор из $n$ линейно независимых решений однородной системы $y'=A(t)y$ называется фундаментальной системой решений (ФСР). Матрица $Y(t)$, столбцами которой являются эти решения, называется фундаментальной матрицей решений (ФМР). 
**Практический алгоритм (для постоянной матрицы $A$):**
1. Найти собственные значения $\lambda_i$ из уравнения $\det(A - \lambda I) = 0$.
2. Найти собственные векторы $v_i$ из $(A - \lambda_i I)v_i = 0$. Решения имеют вид $e^{\lambda_i t}v_i$.
3. Если есть кратные корни (недостаточно векторов), искать присоединенные векторы или умножать на многочлены от $t$ (векторы вида $e^{\lambda t}(v_1 + t v_2 + \dots)$).
4. Записать все $n$ независимых вектор-функций в столбцы — это и есть ФМР $Y(t)$. 
Любое общее решение представимо в виде $y(t) = Y(t)C$, где $C$ — вектор констант.

**7. ФСР, Вронскиан для линейных уравнений высокого порядка**
Любые $n$ линейно независимых решений однородного уравнения $n$-го порядка $y^{(n)} + a_{n-1}y^{(n-1)} + \dots + a_0 y = 0$ образуют ФСР. 
Матрица $U(t)$, составленная из этих решений и их производных до $(n-1)$-го порядка, называется фундаментальной. Определитель этой матрицы называется **определителем Вронского** (Вронскианом) $W(t)$.
**Практическое применение:**
* Если $W(t) \neq 0$ хотя бы в одной точке отрезка, решения образуют ФСР (они линейно независимы).
* Для построения ФСР уравнения с постоянными коэффициентами: пишем характеристический полином $\lambda^n + \dots + a_0 = 0$. Каждому корню $\lambda$ кратности $k$ соответствуют $k$ решений: $e^{\lambda t}, t e^{\lambda t}, \dots, t^{k-1} e^{\lambda t}$. Для комплексных $\alpha \pm i\beta$ это $e^{\alpha t}\cos(\beta t)$ и $e^{\alpha t}\sin(\beta t)$.

**8. Способы вычисления матричной экспоненты ($e^{tA}$)**
Матричная экспонента является ФМР системы $y' = Ay$, удовлетворяющей начальному условию $Y(0) = I$. 
Способы её вычисления:
1. **По определению (ряд Тейлора):** $e^{tA} = I + tA + \frac{t^2}{2!}A^2 + \dots$ (удобно, если $A$ нильпотентна, то есть $A^k=0$, тогда ряд обрывается).
2. **Через жорданову форму:** $A = TJT^{-1} \implies e^{tA} = Te^{tJ}T^{-1}$. Экспонента от жордановой клетки — это матрица с $e^{\lambda t}$ на главной диагонали и $t e^{\lambda t}, \frac{t^2}{2!} e^{\lambda t}$ и т.д. на наддиагоналях.
3. **Через метод Пуассона (через решение задачи Коши):** Искать каждый столбец матрицы как решение системы с начальными условиями $(1,0,0\dots)^T, (0,1,0\dots)^T$ и т.д.
4. **Через $\psi$-функции (самый мощный метод, не требующий поиска собственных векторов!):** Матричная экспонента строится как полином от самой матрицы $A$. $e^{tA} = \psi_1(t)I + \psi_2(t)(A-\tau_1 I) + \psi_3(t)(A-\tau_1 I)(A-\tau_2 I) \dots$ (Подробности в п. 9).

**9. Пси-функции ($\psi$-функции): определение, свойства и применение**
Пси-функции — это специальные скалярные функции времени $\psi(t, \tau_1, \dots, \tau_k)$, зависящие от набора параметров $\tau_i$ (собственных значений матрицы $A$). 
Они позволяют найти матричную экспоненту **без перехода к жордановой форме и без поиска собственных векторов**, только зная характеристический полином.

**Геометрический/математический смысл:** Это аналог разделенных разностей в интерполяционном многочлене Ньютона, но примененный к функции $f(\lambda) = e^{t\lambda}$.

**Свойства $\psi$-функций:**
* $\psi$ симметричны по своим аргументам $\tau_i$ (порядок корней не важен).
* **Для одного корня:** $\psi(t, \tau_1) = e^{\tau_1 t}$.
* **Для двух корней:** 
  * Если $\tau_1 \neq \tau_2$: $\psi(t, \tau_1, \tau_2) = \frac{e^{\tau_1 t} - e^{\tau_2 t}}{\tau_1 - \tau_2}$.
  * Если корни совпадают $\tau_1 = \tau_2$: $\psi(t, \tau_1, \tau_1) = \frac{d}{d\lambda}(e^{\lambda t})|_{\lambda=\tau_1} = t e^{\tau_1 t}$.
* **Для $k$ совпадающих корней:** $\psi(t, \tau, \dots, \tau) = \frac{t^{k-1}}{(k-1)!}e^{\tau t}$.

**Практический алгоритм применения $\psi$-функций для вычисления $e^{tA}$:**
1. Найти собственные значения $\tau_1, \tau_2, \dots, \tau_n$ матрицы $A$ размерности $n \times n$.
2. Вычислить набор $\psi$-функций:
   * $\psi_1 = \psi(t, \tau_1) = e^{\tau_1 t}$
   * $\psi_2 = \psi(t, \tau_1, \tau_2)$
   * $\psi_3 = \psi(t, \tau_1, \tau_2, \tau_3)$ и так до $\psi_n$.
   *(При различных корнях можно считать рекуррентно: $\psi(t, \tau_1, \tau_2, \tau_3) = \frac{\psi(t, \tau_1, \tau_2) - \psi(t, \tau_2, \tau_3)}{\tau_1 - \tau_3}$)*
3. Построить $e^{tA}$ по формуле полинома интерполяции:
   $$ e^{tA} = \psi_1 I + \psi_2 (A - \tau_1 I) + \psi_3 (A - \tau_1 I)(A - \tau_2 I) + \dots + \psi_n (A - \tau_1 I)\dots(A - \tau_{n-1} I) $$
*(Внимание: полином обрывается на $\psi_n$, так как по теореме Гамильтона-Кэли следующий член содержит характеристический многочлен матрицы, который равен нулевой матрице).*

**10. Постановка краевой задачи для систем на всей прямой**
Ищется решение неоднородной системы $y' = Ay + f(t)$, ограниченное на всей числовой прямой $\mathbb{R}$ ($\sup \|y(t)\| < \infty$). 
**Условие разрешимости (Дихотомия):** Матрица $A$ **не должна иметь собственных значений на мнимой оси** ($\text{Re}\lambda_i \neq 0$). 
Геометрический смысл: фазовое пространство расщепляется на два независимых подпространства — устойчивое (решения затухают при $t \to +\infty$) и неустойчивое (затухают при $t \to -\infty$). Если дихотомия есть, задача имеет единственное решение для любой ограниченной правой части $f(t)$. Решение задается интегралом с матричной функцией Грина.

**Что такое функция Грина и как ее считать (для системы на всей прямой):**
Функция Грина $G(t, s)$ (или матрица Грина) — это ядро интегрального оператора, с помощью которого строится решение неоднородной задачи: $y(t) = \int_{-\infty}^{+\infty} G(t, s)f(s)ds$. 
Физический смысл: она показывает "отклик" системы в момент времени $t$ на точечное воздействие (дельта-функцию Дирака), приложенное в момент времени $s$.
**Как считать (практический алгоритм):**
1. Привести матрицу $A$ к блочно-диагональному виду (или использовать спектральное разложение), разделив ее на устойчивую часть $A_-$ (корни с $\text{Re}\lambda < 0$) и неустойчивую часть $A_+$ (корни с $\text{Re}\lambda > 0$). Для этого нужно найти проекторы $P_-$ и $P_+$ на соответствующие инвариантные подпространства ($P_- + P_+ = I$).
2. Матрица Грина для системы с постоянными коэффициентами зависит только от разности аргументов $G(t, s) = G(t-s)$ и строится из матричной экспоненты:
   $$ G(t, s) = \begin{cases} e^{A(t-s)} P_-, & t > s \\ -e^{A(t-s)} P_+, & t < s \end{cases} $$
3. *Альтернативно (для краевой задачи на отрезке $[a,b]$ с условиями $L y(a) + R y(b) = 0$):*
   Функция ищется в виде:
   $$ G(t, s) = \begin{cases} Y(t) C_1(s), & t < s \\ Y(t) C_2(s), & t > s \end{cases} $$
   Матрицы $C_1(s)$ и $C_2(s)$ находятся из системы двух уравнений:
   а) Условие скачка в точке $t=s$: $Y(s)C_2(s) - Y(s)C_1(s) = I \implies C_2(s) - C_1(s) = Y^{-1}(s)$.
   б) Краевые условия: $L \cdot (Y(a)C_1(s)) + R \cdot (Y(b)C_2(s)) = 0$.

**11. Постановка краевой задачи для уравнения высокого порядка на всей прямой**
Ищется решение уравнения с постоянными коэффициентами $P_n(d/dt)u = \varphi(t)$, ограниченное на $\mathbb{R}$. 
**Условие разрешимости:** Характеристический полином $P_n(\lambda)$ не должен иметь корней на мнимой оси (нет чистых мнимых и нулевых корней).
Если это так, то задача имеет единственное ограниченное решение, выражаемое через свертку правой части с функцией Грина: $u(t) = \int_{-\infty}^{+\infty} G(t-s)\varphi(s)ds$.

**12. Постановка краевой задачи на отрезке для систем**
Решается система $y' = A(t)y + f(t)$ на интервале $a < t < b$ с двухточечными краевыми условиями $L y(a) + R y(b) = \varphi$, где $L, R$ — заданные матрицы. 
**Алгоритм проверки разрешимости:**
1. Найти ФМР $Y(t)$ однородной системы $y'=A(t)y$.
2. Подставить ФМР в левую часть краевых условий, получив матрицу $D = L Y(a) + R Y(b)$.
3. Задача однозначно разрешима при любых $f(t)$ и $\varphi$, если $\det D \neq 0$.

**13. Постановка краевой задачи на полупрямой (системы, уравнения)**
Ищется решение $y' = Ay$, ограниченное при $t \ge 0$ (отсекаем растущие экспоненты), с заданным краевым условием в нуле: $B y(0) = \varphi$. 
Однозначно разрешима при выполнении **условия Лопатинского**.
*   **Для системы:** Выделяем устойчивое подпространство матрицы $A$ (соответствующее корням с $\text{Re}\lambda < 0$). Пусть $v_1 \dots v_\mu$ — базис этого подпространства (размерность $\mu$ — число корней в левой полуплоскости). Краевая матрица $B$ должна быть размера $\mu \times n$. Условие Лопатинского: $\det [B(v_1 \dots v_\mu)] \neq 0$.
*   **Для уравнений $n$-го порядка:** Краевые условия задаются операторами $B_j(d/dt)u|_{t=0} = \varphi_j$, каждому соответствует полином $b_j(\tau)$. Полиномы $b_j(\tau)$ должны быть линейно независимы по модулю $P^-(\tau)$ (где $P^-(\tau)$ — полином, составленный только из корней левой полуплоскости).

**Что значит независимость по модулю $P^-(\tau)$?**
Это значит, что краевые условия дают ровно столько уникальной информации, сколько размерность убывающего пространства. 
**Алгоритм:** мы делим каждый краевой полином $b_j(\tau)$ уголком на $P^-(\tau)$. Получаем остатки $r_j(\tau)$. Если эти остатки линейно независимы как обычные многочлены (т.е. определитель матрицы из их коэффициентов не равен нулю), то исходные полиномы $b_j$ независимы по модулю $P^-$, и задача однозначно разрешима.

**14. Постановка краевой задачи на отрезке для уравнений высокого порядка**
Уравнение $n$-го порядка $y^{(n)} + \dots = f(t)$ решается на интервале $a < t < b$ с краевыми условиями на концах (например, $y(a)=0, y'(b)=0$).
В общем виде условия записываются через краевые операторы $U_\mu(y) = \gamma_\mu$. 
**Алгоритм разрешимости:**
1. Найти ФСР $y_1, \dots, y_n$ однородного уравнения.
2. Составить матрицу, применяя краевые операторы к каждому решению ФСР: $m_{ij} = U_i(y_j)$.
3. Задача однозначно разрешима тогда и только тогда, когда определитель этой матрицы $\Delta = \det(m_{ij}) \neq 0$.

**15. Задача Штурма-Лиувилля: что это?**
Это задача о нахождении нетривиальных решений (собственных функций) и параметра $\lambda$ (собственных значений) для краевой задачи вида $u'' + q(t)u = \lambda u$ с краевыми условиями на концах отрезка. Все $\lambda$ вещественны и образуют убывающую (или возрастающую в зависимости от знака перед $\lambda$) к бесконечности последовательность, а собственные функции ортогональны.

**Геометрический смысл:**
Это **ненулевое** решение дифференциального уравнения, содержащего параметр $\lambda$, которое удовлетворяет заданным краевым условиям. Аналогия: как в линейной алгебре $Av = \lambda v$ мы ищем вектор, который не меняет направление, а только растягивается, так и здесь мы ищем функцию, которая под действием дифференциального оператора пропорциональна самой себе. 

**Практический алгоритм решения:**
1. Рассмотреть три случая для параметра $\lambda$: $\lambda < 0$, $\lambda = 0$, $\lambda > 0$ (иногда удобно обозначать $\lambda = -\mu^2, 0, \mu^2$).
2. Для каждого случая найти общее решение уравнения (обычно это экспоненты, линейные функции или синусы/косинусы).
3. Подставить общее решение в краевые условия. Получится однородная система линейных алгебраических уравнений относительно констант $C_1, C_2$.
4. Чтобы решение было нетривиальным (не равным тождественно нулю), определитель этой системы должен быть равен нулю. Из этого условия находим собственные значения $\lambda_n$.
5. Подставляя найденные $\lambda_n$ обратно, находим соответствующие константы и выписываем собственные функции $u_n(t)$ (они определены с точностью до константы-множителя).

**16. Определения устойчивости по Ляпунову**
Решение $\bar{y}(t)$ устойчиво, если для любого $\varepsilon > 0$ существует $\delta > 0$ такое, что при начальном отклонении $\|y(t_0) - \bar{y}(t_0)\| < \delta$, отклонение решений $\|y(t) - \bar{y}(t)\| < \varepsilon$ сохраняется для всех $t \ge t_0$.
**Геометрический смысл:** Если мы начнем движение достаточно близко от невозмущенной траектории $\bar{y}(t)$ (внутри трубки радиуса $\delta$), то мы никогда не отдалимся от неё дальше, чем на $\varepsilon$ (останемся в $\varepsilon$-трубке).

**17. Определение асимптотической устойчивости**
Решение асимптотически устойчиво, если оно устойчиво по Ляпунову и дополнительно существует $\delta_0 > 0$, при котором $\|y(t_0) - \bar{y}(t_0)\| < \delta_0 \implies \|y(t) - \bar{y}(t)\| \to 0$ при $t \to \infty$.
**Геометрический смысл:** Траектория не просто остается рядом, но и с течением времени "притягивается" к невозмущенному решению, сливаясь с ним в бесконечности.

**18. Неустойчивость**
Отсутствие устойчивости по Ляпунову. Возникает, если хотя бы одна траектория, начавшаяся сколь угодно близко к $\bar{y}(t)$, со временем покинет $\varepsilon$-окрестность.

**Практические алгоритмы исследования на устойчивость (по первому приближению):**
Рассматривается система $\dot{y} = Ay + f(y)$, где $f(y)$ — нелинейность высокого порядка малости. Устойчивость нулевого решения определяется собственными значениями $\lambda_i$ матрицы $A$ (матрицы Якоби, вычисленной в точке равновесия):
1. Если **все** $\text{Re} \lambda_i < 0$ — нулевое решение **асимптотически устойчиво**.
2. Если есть **хотя бы одно** $\text{Re} \lambda_i > 0$ — нулевое решение **неустойчиво**.
3. Если максимальная $\text{Re} \lambda_i = 0$ (есть нулевые или чисто мнимые корни, а остальные с отрицательной вещественной частью) — **критический случай**. Линейное приближение не дает ответа, нужно исследовать нелинейные члены (например, используя функцию Ляпунова, см. п. 5).

**Для чисто линейных систем $y' = Ay$:**
* Асимптотическая устойчивость $\iff$ все $\text{Re} \lambda_i < 0$.
* Устойчивость (но не асимптотическая) $\iff$ все $\text{Re} \lambda_i \le 0$, причем корни с нулевой вещественной частью имеют простые элементарные делители (отсутствуют жордановы клетки размера $> 1$ для чисто мнимых и нулевых корней).
* Неустойчивость $\iff$ есть $\text{Re} \lambda_i > 0$ ИЛИ есть кратные корни на мнимой оси с жордановыми клетками $> 1$ (что дает рост вида $t \sin(\beta t)$).

**19. Определение матрицы монодромии, мультипликаторы**
Для систем с периодическими коэффициентами $A(t+T)=A(t)$, матрица монодромии $B$ связывает фундаментальную матрицу решений на периоде: $Y(t+T) \equiv Y(t)B$. Ее собственные значения называются **мультипликаторами** $\mu_i$. 

**Практическое использование:**
Как найти матрицу монодромии? Если $Y(t)$ — ФМР, нормированная в нуле (т.е. $Y(0) = I$), то матрица монодромии просто равна значению ФМР в конце первого периода: $B = Y(T)$.
Исследование на устойчивость (аналог собственных значений для автономных систем):
* Если все $|\mu_i| < 1$, то нулевое решение **асимптотически устойчиво**.
* Если есть хотя бы один $|\mu_i| > 1$, то **неустойчиво**.
* Если все $|\mu_i| \le 1$, и для тех, у которых $|\mu| = 1$, нет жордановых клеток $>1$, то просто **устойчиво**.

**20. Первые интегралы (определение)**
Функция $\Phi(t,y) \not\equiv \text{const}$ называется первым интегралом системы, если вдоль любой её фазовой траектории она сохраняет постоянное значение: $\Phi(t,y(t)) \equiv \text{const}$. Если функция гладкая, то полная производная равна нулю: $\frac{\partial\Phi}{\partial t} + \sum f_j \frac{\partial\Phi}{\partial y_j} = 0$.

**Подробный смысл и практическое применение:**
Физическая аналогия — закон сохранения энергии или импульса. 
**Как искать?** Систему ОДУ часто записывают в симметричной форме: $\frac{dt}{1} = \frac{dy_1}{f_1} = \frac{dy_2}{f_2} = \dots$. Ищем так называемые *интегрируемые комбинации* — используем свойства пропорций, чтобы получить выражение вида $d(\text{что-то}) = 0$. Тогда "что-то" $= C$ и есть первый интеграл.
Если мы найдем $k$ независимых первых интегралов, мы сможем выразить $k$ переменных через другие алгебраически, понизив порядок системы. Также первые интегралы — это главный инструмент для решения уравнений в частных производных (УРЧП).

**21. Задача Коши для уравнений с частными производными 1-го порядка (постановка)**
Уравнение вида $f_0 u_t + \sum_{j=1}^n f_j u_{y_j} = g$. (Или в автономном виде $f_1 u_{x_1} + \dots + f_n u_{x_n} = 0$). 
Задача Коши: найти решение-поверхность $u(t, y_1 \dots y_n)$, проходящее через заданную начальную гиперповерхность (удовлетворяющее начальному условию $u|_{t=t_0} = \varphi(y)$). 

**22. Что такое характеристики для уравнений с частными производными 1-порядка и алгоритм решения**
Характеристики — это фазовые траектории (кривые) автономной системы обыкновенных дифференциальных уравнений, ассоциированной с УРЧП. 
**Геометрический смысл:** Решение УРЧП (интегральная поверхность) соткано из этих кривых-характеристик. Вдоль характеристики значение искомой функции $u$ ведет себя очень просто (оно либо постоянно для однородных УРЧП, либо изменяется по известному закону).

**Практический алгоритм решения (Метод характеристик):**
1. Выписать **уравнения характеристик** в симметричной форме: 
   $$ \frac{dt}{f_0} = \frac{dy_1}{f_1} = \dots = \frac{dy_n}{f_n} = \frac{du}{g} $$
   (для однородного уравнения последнего члена нет).
2. Найти базис из независимых **первых интегралов** этой системы ОДУ: $\Phi_1(t, y, u) = C_1, \dots, \Phi_n = C_n$.
3. **Общее решение** УРЧП задается неявным уравнением $F(\Phi_1, \dots, \Phi_n) = 0$, где $F$ — произвольная дифференцируемая функция.
4. **Решение задачи Коши:** Подставить начальное условие $u|_{t=t_0} = \varphi(y)$ в найденные интегралы $\Phi_i$. Это даст связь между константами $C_i$. Исключив переменные $y_i$, мы получим конкретную связь $F(C_1, \dots) = 0$. Подставив обратно функции $\Phi_i$ вместо $C_i$, получим частное решение.
