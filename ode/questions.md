1→1. Задача Коши для систем нелинейных дифференциальных уравнений. Теорема Пикара. Доказательство существования решения.
**Ответ:** (Теорема 1.1.2, стр. 9-13). Задача Коши: $y' = f(t,y)$, $y(t_0) = y^0$. Теорема Пикара утверждает, что если $f(t,y)$ непрерывна в цилиндрической области и удовлетворяет там условию Липшица по $y$, то существует единственное решение на локальном отрезке $|t - t_0| \le T_0$. Существование доказывается переходом к эквивалентному интегральному уравнению и построением последовательности приближений Пикара: $y^{[m]}(t) = y^0 + \int_{t_0}^t f(s, y^{[m-1]}(s))ds$. Доказывается индукцией, что все $y^{[m]}$ лежат в цилиндре. Равномерная сходимость доказывается оценкой разностей соседних приближений (мажоранта в виде сходящегося ряда Тейлора для экспоненты), после чего предел подставляется в интегральное уравнение.

2. Задача Коши для систем нелинейных дифференциальных уравнений. Теорема Пикара. Доказательство единственности решения.
**Ответ:** (стр. 14-15). Доказательство проводится от противного. Предполагается наличие двух решений $y^1(t)$ и $y^2(t)$. Для их разности из интегрального уравнения и условия Липшица выводится оценка $\|y^2(t) - y^1(t)\| \le L \int_{t_0}^t \|y^2(s) - y^1(s)\|ds$. Вводя $v(t) = L \int_{t_0}^t \|y^2(s) - y^1(s)\|ds$, получаем дифференциальное неравенство $v'(t) - L v(t) \le 0$. Умножая на $e^{-Lt}$, получаем $(e^{-Lt}v(t))' \le 0$, откуда интегрированием следует $v(t) \equiv 0$ для $t \ge t_0$. Следовательно, $\|y^2(t) - y^1(t)\| = 0$, решения совпадают.

3. Задача Коши для систем линейных дифференциальных уравнений. Теорема об однозначной разрешимости.
**Ответ:** (Теорема 1.1.4, стр. 17). Для системы $y' = A(t)y + h(t)$, где матрица $A(t)$ и вектор $h(t)$ непрерывны на интервале $(t_-, t_+)$. Теорема утверждает, что при любых начальных данных из этого интервала существует единственное решение, определенное на всем интервале $(t_-, t_+)$. Доказательство использует метод Пикара: на любом замкнутом подотрезке правая часть непрерывна и удовлетворяет условию Липшица глобально (с константой $\max \|A(s)\|$). Это обеспечивает сходимость приближений Пикара на всем подотрезке. В силу произвольности подотрезка решение продолжается на весь интервал $(t_-, t_+)$.

4. Неоднородные системы линейных дифференциальных уравнений. Метод вариации произвольной постоянной.
**Ответ:** (Упр. 1.1.1, стр. 21). Для системы $y' = Ay + h(t)$ с постоянной матрицей $A$ решение задачи Коши выражается формулой: $y(t) = e^{(t-t_0)A}y^0 + \int_{t_0}^t e^{(t-s)A}h(s)ds$ (формула Коши). В общем случае для систем с переменной матрицей применяется метод вариации постоянных: общее решение однородной системы записывается как $Y(t)C$, где $Y(t)$ — фундаментальная матрица. Для неоднородной системы решение ищется в виде $Y(t)C(t)$, подстановка в уравнение дает $Y(t)C'(t) = h(t)$, откуда $C(t)$ находится интегрированием.

5. Непродолжаемые решения. Доказательство существования и единственности непродолжаемого решения задачи Коши.
**Ответ:** (Теорема 1.2.1, стр. 25-28). Решение называется непродолжаемым, если оно не имеет продолжения ни влево, ни вправо. Для локально липшицевой правой части доказывается лемма о том, что решения с одинаковыми начальными данными совпадают на пересечении интервалов их существования. Непродолжаемое решение строится путем объединения (склейки) всех возможных решений данной задачи Коши. Интервалом существования непродолжаемого решения является объединение интервалов всех этих решений. Корректность обеспечивается леммой о совпадении, единственность гарантируется локальной теоремой единственности.
6. Теорема о покидании компакта для непродолжаемых решений.
**Ответ:** (Теорема 1.2.2, стр. 28-30). Пусть $y(t)$ — непродолжаемое решение системы $y'=f(t,y)$, определенное на интервале $(t_-, t_+)$, и $K$ — связное компактное множество, лежащее в области определения правой части $G$. Теорема утверждает, что если интегральная кривая $(t, y(t))$ имеет непустое пересечение с $K$, то существует отрезок $[t_1, t_2] \subset (t_-, t_+)$ такой, что интегральная кривая находится вне компакта $K$ при $t \notin [t_1, t_2]$. Иными словами, непродолжаемое решение обязательно покидает любой компакт, лежащий внутри области $G$. Доказательство проводится от противного с использованием свойств компакта и построения цилиндра Пеано-Пикара.

7. Теорема Ляпунова о существовании решения задачи Коши на полуоси.
**Ответ:** (Теорема 1.2.5, стр. 34-37). Рассматривается автономная система $y'=f(y)$ с условием $f(0)=0$. Если в шаре $B_r$ существует функция Ляпунова $H(y)$ (т.е. $H \in C^1$, $H(y) \ge 0$ и $H(y)=0 \iff y=0$, а также производная в силу системы $\langle \nabla H(y), f(y) \rangle \le 0$), то найдется достаточно малое $\rho_0 \in (0, r)$ такое, что для любых начальных данных $y^0$ из шара $B_{\rho_0}$ непродолжаемое решение задачи Коши будет определено на всей правой полуоси $t \ge 0$. Доказательство базируется на том, что значение функции Ляпунова не возрастает вдоль решений, что не дает решению покинуть шар $B_r$ (оценки решения через $H(y)$ ограничивают его норму), поэтому решение продолжается бесконечно вправо.

8. Непрерывная зависимость решений задачи Коши от начальных данных и параметров.
**Ответ:** (Теоремы 1.3.1 и 1.3.2, стр. 43-52). Если правая часть системы $F(t,y,\mu)$ непрерывна по совокупности переменных и локально удовлетворяет условию Липшица по $y$, то решения непрерывно зависят от параметров $\mu$ (Теорема 1.3.1). Доказательство опирается на интегральное неравенство Гронуолла (Лемма 1.3.1), которое позволяет оценить разность двух решений через разность параметров. Аналогично устанавливается непрерывная зависимость от начальных данных $t_0, y^0$ (Теорема 1.3.2) путем сведения задачи к системе с параметрами с помощью подходящей замены переменных. Множество существования решений при этом является открытым.

9. Лемма Адамара.
**Ответ:** (Лемма 1.4.1, стр. 55). Лемма является многомерным аналогом формулы Лагранжа (или формулы конечных приращений). Она утверждает, что если вектор-функция $g(u,v)$ непрерывна и имеет непрерывные частные производные по переменным $v_j$ в области $U \times V$, причем $V$ — выпуклая область, то разность значений функции в точках $v^2$ и $v^1$ можно представить в виде: $g(u, v^2) - g(u, v^1) = A(u, v^1, v^2)(v^2 - v^1)$, где $A$ — матрица с непрерывными элементами. Доказывается с использованием формулы Ньютона-Лейбница для вспомогательной функции от скалярного параметра $\lambda \in [0,1]$, соединяющего отрезком точки $v^1$ и $v^2$.

10. Дифференцируемая зависимость решений задачи Коши от параметров. Уравнения Пуанкаре в вариациях.
**Ответ:** (Теорема 1.4.1, стр. 52-60). Если правая часть системы $F(t,y,\mu)$ имеет непрерывные частные производные по $y_j$ и параметрам $\mu_l$, то непродолжаемое решение $y(t,\mu)$ имеет непрерывные частные производные по параметрам $\mu_l$. Более того, вектор-функция производных по параметру $v^l(t, \mu) = \frac{\partial y}{\partial \mu_l}$ удовлетворяет линейной системе дифференциальных уравнений $\frac{d v^l}{dt} = A(t,\mu)v^l + h^l(t,\mu)$ с нулевым начальным условием $v^l|_{t=t_0} = 0$. Здесь матрица $A = \frac{\partial F}{\partial y}$, а неоднородность $h^l = \frac{\partial F}{\partial \mu_l}$ вычислены на решении $y(t,\mu)$. Эта линейная система называется системой уравнений в вариациях Пуанкаре. Доказательство использует лемму Адамара для оценки приращения решения и предельного перехода.
11. Дифференцируемая зависимость решений задачи Коши от компонент начального вектора. Уравнения Пуанкаре в вариациях.
**Ответ:** (Теорема 1.4.2, стр. 61-63). Если вектор-функция непрерывна и имеет непрерывные частные производные по $y_j$, то существует единственное непродолжаемое решение задачи Коши, которое дифференцируемо по компонентам начального вектора $\xi$. Вектор-функции частных производных $v^i(t,\xi) = \frac{\partial y}{\partial \xi_i}$ являются решениями линейной системы дифференциальных уравнений $dv^i/dt = f_y(t, y(t,\xi))v^i$ с начальным условием $v^i|_{t=t_0} = e^i$ (базисный вектор). Эта система называется системой уравнений в вариациях Пуанкаре по компонентам начального вектора. Из этого выводится формула Лиувилля для определителя матрицы Якоби.

12. Пространство решений однородных систем линейных дифференциальных уравнений.
**Ответ:** (Теоремы 2.1.1 и 2.1.3, стр. 79-82). Для однородной системы линейных дифференциальных уравнений $y' = A(t)y$ множество всех решений образует линейное пространство (в силу линейности самой системы). Размерность этого пространства решений в точности равна $n$, где $n$ — порядок системы. Базис пространства можно построить, взяв $n$ линейно независимых векторов начальных данных и найдя соответствующие им решения задачи Коши.

13. Фундаментальная система решений систем линейных дифференциальных уравнений. Фундаментальная матрица решений. Теорема Остроградского-Лиувилля.
**Ответ:** (стр. 83-88). Набор из $n$ линейно независимых решений системы называется фундаментальной системой решений. Матрица $Y(t)$, столбцами которой являются эти решения, называется фундаментальной матрицей решений. Любое решение представимо в виде $y(t) = Y(t)C$. Теорема Остроградского-Лиувилля (Теорема 2.1.6) утверждает, что определитель фундаментальной матрицы (определитель Вронского) удовлетворяет дифференциальному уравнению $dw/dt = \text{tr}(A(t))w$ и выражается формулой: $w(t) = w(t_0) \exp\left(\int_{t_0}^t \text{tr}(A(\xi)) d\xi \right)$.

14. Задача Коши для систем линейных дифференциальных уравнений с постоянными коэффициентами. Формула Коши.
**Ответ:** (Следствие 2.2.2, стр. 92-93). Для неоднородной системы с постоянными коэффициентами $y' = Ay + h(t)$ решение задачи Коши $y(t_0)=y^0$ задается формулой Коши: $y(t) = e^{(t-t_0)A}y^0 + \int_{t_0}^t e^{(t-s)A}h(s)ds$. Первое слагаемое описывает общее решение однородной системы, а второе (интеграл) — частное решение неоднородной системы. Вывод основан на применении метода вариации постоянных к фундаментальной матрице $e^{tA}$.

15. Свойства матричной экспоненты. Различные способы вычисления матричной экспоненты.
**Ответ:** (Стр. 85-87, 100-110). Матричная экспонента $e^{tA}$ является фундаментальной матрицей системы $y'=Ay$. Основные свойства: $e^{(t-\tau)A} \equiv e^{tA}e^{-\tau A}$, $(e^{tA})^{-1} \equiv e^{-tA}$, коммутирует с $A$. Способы вычисления: 1) Через жорданову форму $A = TJT^{-1} \implies e^{tA} = Te^{tJ}T^{-1}$, где для жордановой клетки экспонента строится явно (стр. 100). 2) С помощью специальных функций (Теорема 2.3.2, стр. 110) как линейная комбинация степеней матрицы: $e^{tA} = \psi(t,\tau_1)I + \psi(t,\tau_1,\tau_2)(A-\tau_1 I) + \dots + \psi(t,\tau_1,\dots,\tau_n)(A-\tau_1 I)\dots(A-\tau_{n-1} I)$, где $\tau_i$ — собственные значения матрицы $A$, что позволяет избежать поиска собственных векторов.
16. Оценки норм матричной экспоненты. Лемма Гельфанда-Шилова.
**Ответ:** (Теорема 2.3.3, стр. 110-112). Если для собственных значений матрицы $A$ выполнено $\text{Re } \tau_j \le \sigma$, то при $t \ge 0$ норма матричной экспоненты допускает оценку $\|e^{tA}\| \le e^{\sigma t} \sum_{k=0}^{n-1} \frac{(2t\|A\|)^k}{k!}$. Доказательство основано на представлении матричной экспоненты в виде матричного полинома (через $\psi$-функции) и оценке этих функций индукцией.

17. Непрерывная зависимость для линейных систем дифференциальных уравнений.
**Ответ:** (Теорема 2.2.3, стр. 96-98). Решение задачи Коши для линейной системы непрерывно зависит от матрицы системы, вектора неоднородности и начальных данных. Если изменения $\tilde{A}(t)$, $\tilde{h}(t)$ и $\tilde{y}^0$ малы, то и отклонение решения $\tilde{y}(t)$ от $y(t)$ будет малым. Доказательство опирается на применение леммы Гронуолла к интегральному уравнению для разности решений. Также доказывается, что матричная экспонента $e^{tA}$ непрерывно зависит от элементов матрицы $A$ (Следствие 2.2.4).

18. Задача Коши для линейных дифференциальных уравнений высокого порядка.
**Ответ:** (стр. 112-114, 118-119). Линейное уравнение $n$-го порядка $u^{(n)} + a_1(t)u^{(n-1)} + \dots + a_n(t)u = \varphi(t)$ эквивалентно системе $n$ уравнений первого порядка $y' = A_n(t)y + h(t)$, где компоненты $y$ — это функция $u$ и ее производные до $(n-1)$-го порядка. Задача Коши ставится как задание значений $u(t_0)=u_0, u'(t_0)=u_1, \dots, u^{(n-1)}(t_0)=u_{n-1}$. Теорема 2.4.2 утверждает существование и единственность решения этой задачи Коши в силу эквивалентности задаче Коши для соответствующей системы первого порядка.

19. Фундаментальная матрица решений линейных дифференциальных уравнений высокого порядка. Определитель Вронского. Формула Остроградского-Лиувилля.
**Ответ:** (стр. 115-116, 121-122). Любые $n$ линейно независимых решений однородного уравнения $n$-го порядка образуют фундаментальную систему. Матрица $U(t)$, составленная из этих решений и их производных до $(n-1)$-го порядка, называется матрицей Вронского, а ее определитель $\det U(t)$ — определителем Вронского (вронскианом). Для вронскиана справедлива формула Остроградского-Лиувилля: $\det U(t) = \det U(t_0) \exp(-\int_{t_0}^t a_1(\xi)d\xi)$ (Теорема 2.4.3), которая вытекает из применения аналогичной формулы для эквивалентной линейной системы, учитывая, что след матрицы системы равен $-a_1(t)$.

20. Способы нахождения фундаментальной системы решений линейных дифференциальных уравнений произвольного порядка с постоянными коэффициентами.
**Ответ:** (стр. 122-130). Для уравнения с постоянными коэффициентами составляется характеристический полином $P_n(\tau) = \tau^n + a_1\tau^{n-1} + \dots + a_n = 0$. Его корни $\tau_1, \dots, \tau_n$ определяют фундаментальную систему решений. Построение сводится к решению серии простых задач Коши для дифференциальных операторов первого порядка. Полученные базисные решения выражаются через специальные функции $\psi(t, \tau_1, \dots, \tau_k)$, которые вычисляются рекуррентно (через интегралы от экспонент).

21. Пространство решений однородных линейных дифференциальных уравнений произвольного порядка.
**Ответ:** (Теорема 2.4.1, стр. 113). Множество всех решений однородного линейного дифференциального уравнения $n$-го порядка $u^{(n)} + a_1(t)u^{(n-1)} + \dots + a_n(t)u = 0$ образует линейное пространство размерности $n$. Доказательство опирается на эквивалентность данного уравнения системе линейных дифференциальных уравнений первого порядка размерности $n$, для которой аналогичное утверждение уже доказано.

22. Свойства пси-функций.
**Ответ:** (стр. 130-135). Пси-функции $\psi(t, \tau_1, \dots, \tau_k)$, определяющие фундаментальную систему решений линейного уравнения с постоянными коэффициентами, обладают свойствами: 1) непрерывность по всем переменным; 2) симметричность по аргументам $\tau_i$; 3) вектор из пси-функций является решением специальной задачи Коши; 4) если все корни совпадают, то $\psi = \frac{t^{k-1}}{(k-1)!}e^{\tau t}$; 5) если все корни различны, функция является линейной комбинацией экспонент; 6) если корни разбиты на группы, функция представима в виде комбинации пси-функций от подгрупп.

23. Краевая задача на числовой прямой для линейных систем дифференциальных уравнений с постоянными коэффициентами.
**Ответ:** (Теорема 3.1.1, стр. 145-147). Задача об отыскании решения системы $y' = Ay + f(t)$, ограниченного на всей числовой прямой $\mathbb{R}$ ($\sup \|y(t)\| < \infty$). Если матрица $A$ не имеет собственных значений на мнимой оси (условие дихотомии), то для любой непрерывной ограниченной функции $f(t)$ существует единственное ограниченное на $\mathbb{R}$ решение. Справедлива оценка $\sup \|y(t)\| \le c \sup \|f(t)\|$.

24. Матрица Грина краевой задачи на числовой прямой для линейных систем дифференциальных уравнений с постоянными коэффициентами.
**Ответ:** (стр. 153-156). Матрицей Грина $G(t)$ называется матричная функция, позволяющая представить ограниченное решение в виде $y(t) = \int_{-\infty}^{\infty} G(t-s)f(s)ds$. Ее свойства: 1) является решением уравнения $dG(t)/dt = AG(t)$ при $t \ne 0$; 2) имеет в нуле скачок $G(+0) - G(-0) = I$ (единичная матрица); 3) экспоненциально убывает на бесконечности $\|G(t)\| \le c e^{-\delta|t|/2}$, где $\delta$ связано с расстоянием спектра $A$ до мнимой оси.

25. Краевая задачи на числовой прямой для линейных дифференциальных уравнений произвольного порядка с постоянными коэффициентами.
**Ответ:** (Теорема 3.2.1, стр. 160-161). Рассматривается задача поиска ограниченного на $\mathbb{R}$ решения $P_n(d/dt)u = \varphi(t)$. Если характеристический полином $P_n(\tau)$ не имеет корней на мнимой оси ($|\text{Re }\tau_j| \ge \delta > 0$), то для любой непрерывной ограниченной $\varphi(t)$ существует единственное ограниченное решение $u(t) \in C^n(\mathbb{R})$, удовлетворяющее оценке $\sup |u(t)| \le c \sup |\varphi(t)|$. Доказательство сводится к эквивалентной задаче для системы уравнений первого порядка.
26. Функция Грина краевой задачи на числовой прямой для линейных дифференциальных уравнений произвольного порядка с постоянными коэффициентами.
**Ответ:** (Теоремы 3.2.2, 3.2.3, Определение 3.2.1, стр. 162-165). Решение задачи $P_n(d/dt)u = \varphi(t)$ на числовой прямой можно представить в виде интеграла: $u(t) = \int_{-\infty}^{\infty} g(t-s)\varphi(s)ds$, где $g(t)$ — функция Грина. Она обладает свойствами: 1) удовлетворяет однородному уравнению $P_n(d/dt)g(t) \equiv 0$ при $t \ne 0$; 2) $g(t) \in C^{n-2}(\mathbb{R})$, а производная $g^{(n-1)}$ имеет в нуле скачок $g^{(n-1)}(+0) - g^{(n-1)}(-0) = 1$; 3) ограничена на всей прямой $\sup_{t \in \mathbb{R}} |g(t)| < \infty$. Эти свойства однозначно определяют функцию Грина. Ее построение зависит от распределения корней характеристического полинома (все слева, все справа или дихотомия).

27. Краевые задачи на полупрямой для линейных систем дифференциальных уравнений с постоянными коэффициентами. Условие Лопатинского.
**Ответ:** (Теорема 3.3.1, Определение 3.3.1, стр. 167-173). Рассматривается задача $y' = Ay + f(t)$ при $t > 0$ с краевым условием $B y|_{t=0} = \varphi$ и требованием ограниченности решения $\sup_{t>0}\|y(t)\| < \infty$. Пусть матрица $A$ имеет $\mu$ собственных значений в левой полуплоскости и не имеет чисто мнимых. Пусть $v_1, \dots, v_\mu$ — базис инвариантного подпространства, отвечающего собственным значениям из левой полуплоскости. Краевая задача имеет единственное ограниченное решение при любых непрерывных ограниченных $f(t)$ и векторах $\varphi$ тогда и только тогда, когда матрица $B$ имеет размер $\mu \times n$ и выполнено условие Лопатинского: $\det B(v_1 \dots v_\mu) \ne 0$.

28. Краевые задачи на полупрямой для линейных дифференциальных уравнений высокого порядка с постоянными коэффициентами. Условие Лопатинского.
**Ответ:** (Теорема 3.3.2, Определение 3.3.2, стр. 174-176). Ищется ограниченное при $t>0$ решение уравнения $P_n(d/dt)u = h(t)$ с условиями $b_j(d/dt)u|_{t=0} = \psi_j$, $j=1,\dots,\mu$, где $\mu$ — число корней характеристического полинома $P_n(\tau)$ в левой полуплоскости (чисто мнимых нет). Обозначим $P^-(\tau)$ полином, составленный из корней левой полуплоскости. Условие Лопатинского заключается в линейной независимости полиномов $b_j(\tau)$ по модулю $P^-(\tau)$, что эквивалентно условию $\det B \ne 0$, где матрица $B$ составлена из коэффициентов остатков от деления $b_j(\tau)$ на $P^-(\tau)$. При его выполнении задача однозначно разрешима.

29. Краевые задачи на отрезке для линейных систем дифференциальных уравнений. Условие однозначной разрешимости.
**Ответ:** (Теорема 3.4.1, стр. 180-182). Рассматривается краевая задача на интервале: $y' = A(t)y + f(t)$, $a < t < b$, с краевыми условиями $L y|_{t=a} + R y|_{t=b} = \varphi$. Пусть $Y(t)$ — фундаментальная матрица решений однородной системы. Условие однозначной разрешимости краевой задачи при любых $f(t)$ и $\varphi$ имеет вид $\Delta = \det(LY(a) + RY(b)) \ne 0$. Выполнение этого условия эквивалентно тому, что соответствующая однородная краевая задача имеет только тривиальное решение. Условие не зависит от выбора фундаментальной матрицы.

30. Матрица Грина для краевой задачи на отрезке для линейных систем дифференциальных уравнений.
**Ответ:** (Определение 3.4.2, Теорема 3.4.3, стр. 184-187). Если условие однозначной разрешимости выполнено, решение задачи представляется в виде интеграла: $y(t) = Y(t)(LY(a)+RY(b))^{-1}\varphi + \int_a^b G(t,s)f(s)ds$, где $G(t,s)$ — матрица Грина. Свойства $G(t,s)$: 1) при $t \ne s$ удовлетворяет тождеству $\frac{\partial}{\partial t}G(t,s) \equiv A(t)G(t,s)$; 2) имеет скачок при $t=s$: $G(s+0, s) - G(s-0, s) = I$; 3) удовлетворяет однородным краевым условиям $L G(a,s) + R G(b,s) = 0$. Эти три свойства определяют матрицу Грина единственным образом.
31. Краевые задачи на отрезке для линейных дифференциальных уравнений произвольного порядка. Условие однозначной разрешимости.
**Ответ:** (Теорема 3.4.4, стр. 189-190). Рассматривается краевая задача для уравнения $n$-го порядка $P_n(t, d/dt)u = h(t)$ на интервале $a < t < b$ с краевыми условиями $L U(a) + R U(b) = \psi$, где $U$ — вектор из функции и ее производных до $(n-1)$ порядка. Теорема утверждает, что краевая задача однозначно разрешима при любых $h(t)$ и $\psi$ тогда и только тогда, когда определитель $\Delta = \det(LY(a) + RY(b)) \ne 0$, где $Y(t)$ — фундаментальная матрица решений эквивалентной однородной системы первого порядка.

32. Функция Грина для краевой задачи на отрезке для линейных дифференциальных уравнений высокого порядка.
**Ответ:** (Теорема 3.4.5, Определение 3.4.3, стр. 191-192). Если выполнено условие однозначной разрешимости, решение краевой задачи при нулевых краевых условиях представимо в виде $u(t) = \int_a^b g(t,s)h(s)ds$, где $g(t,s)$ — функция Грина. Она обладает свойствами: 1) удовлетворяет однородному уравнению по $t$ при $t \ne s$; 2) производные по $t$ до $(n-2)$-го порядка непрерывны при $t=s$, а $(n-1)$-я производная имеет скачок, равный 1; 3) удовлетворяет однородным краевым условиям. Эти свойства определяют функцию Грина единственным образом.

33. Задача Штурма-Лиувилля. Свойства собственных функций и собственных значений.
**Ответ:** (стр. 195-197). Задачей Штурма-Лиувилля называется задача о нахождении нетривиальных решений (собственных функций) и соответствующих им значений параметра $\lambda$ (собственных значений) для краевой задачи вида $u'' + q(t)u = \lambda u$ с краевыми условиями на концах отрезка. Свойства (Теоремы 3.5.1-3.5.4): 1) каждому собственному значению соответствует ровно одна линейно независимая собственная функция; 2) собственные функции, соответствующие разным собственным значениям, ортогональны в $L_2(a,b)$; 3) все собственные значения вещественны; 4) существует счетное число собственных значений, они образуют убывающую последовательность $\lambda_1 > \lambda_2 > \dots$, стремящуюся к $-\infty$.

34. Устойчивость по Ляпунову решений однородных систем линейных дифференциальных уравнений.
**Ответ:** (Определение 4.1.1, Теорема 4.2.1, стр. 215, 218). Решение $\bar{y}(t)$ называется устойчивым по Ляпунову, если для любого $\varepsilon > 0$ существует $\delta_\varepsilon > 0$ такое, что для любого решения $y(t)$ с начальными данными $\|y(t_0) - \bar{y}(t_0)\| < \delta_\varepsilon$, выполняется $\|y(t) - \bar{y}(t)\| < \varepsilon$ для всех $t \ge t_0$. Для однородной линейной системы $y'=A(t)y$ нулевое решение устойчиво по Ляпунову тогда и только тогда, когда любое ее решение ограничено при $t \ge 0$ (т.е. $\sup_{t \ge 0}\|Y(t)\| < \infty$).

35. Асимптотическая устойчивость решений однородных систем линейных дифференциальных уравнений.
**Ответ:** (Определение 4.1.2, Следствия 4.2.2-4.2.3, стр. 215, 220). Решение называется асимптотически устойчивым, если оно устойчиво по Ляпунову и существует $\delta_0 > 0$ такое, что при $\|y(t_0) - \bar{y}(t_0)\| < \delta_0$ выполняется $\|y(t) - \bar{y}(t)\| \to 0$ при $t \to \infty$. Для однородной линейной системы $y'=A(t)y$ нулевое решение асимптотически устойчиво тогда и только тогда, когда для любого ее решения $y(t) \to 0$ при $t \to \infty$, что эквивалентно условию $\|Y(t)\| \to 0$ при $t \to \infty$ для фундаментальной матрицы $Y(t)$.
36. Спектральный критерий устойчивости нулевого решения однородных систем линейных дифференциальных уравнений с постоянными коэффициентами.
**Ответ:** (Теоремы 4.2.4-4.2.6, 4.2.7(II), стр. 221-224). Нулевое решение системы $y' = Ay$ устойчиво по Ляпунову тогда и только тогда, когда все собственные значения матрицы $A$ лежат в левой полуплоскости $\{\lambda \in \mathbb{C} : \text{Re}\lambda \le 0\}$, причем для любого собственного значения $\lambda_k$ с $\text{Re}\lambda_k = 0$ в жордановой форме матрицы $A$ соответствуют только одномерные жордановы клетки (то есть нет присоединенных векторов). Доказательство основано на представлении матричной экспоненты через жорданову форму: экспоненты от клеток с $\text{Re}\lambda < 0$ стремятся к нулю (по лемме Гельфанда-Шилова), для клеток с $\text{Re}\lambda = 0$ размерности 1 норма экспоненты равна 1. Если есть $\text{Re}\lambda > 0$, решение неограниченно растет (неустойчивость). Если есть клетка с $\text{Re}\lambda = 0$ размерности $>1$, возникает слагаемое вида $te^{\lambda t}$, норма которого растет как $t$, что также дает неустойчивость.

37. Спектральный критерий асимптотической устойчивости нулевого решения однородных систем линейных дифференциальных уравнений с постоянными коэффициентами.
**Ответ:** (Теорема 4.2.2, 4.2.7(I), стр. 220-221, 223). Нулевое решение системы $y' = Ay$ асимптотически устойчиво тогда и только тогда, когда все собственные значения матрицы $A$ лежат строго в левой полуплоскости, то есть $\text{Re}\lambda_j < 0$ для $j=1,\dots,n$. Достаточность доказывается применением леммы Гельфанда-Шилова к матричной экспоненте $e^{tA}$: так как $\text{Re}\lambda_j \le -\delta < 0$, норма экспоненты ограничена сверху функцией $e^{-\delta t} \cdot P(t)$ (где $P(t)$ — полином), которая стремится к нулю при $t \to \infty$. Следовательно, $\|Y(t)\| \to 0$. Необходимость (Теорема 4.2.3) доказывается от противного: если есть собственное значение с $\text{Re}\lambda \ge 0$, то существует решение $y(t) = e^{\lambda t}v$ (где $v$ — собственный вектор), норма которого $\|e^{\lambda t}v\| = e^{\text{Re}\lambda t}\|v\|$ не стремится к нулю при $t \to \infty$, что противоречит определению асимптотической устойчивости.

38. Матричное уравнение Ляпунова.
**Ответ:** (Теорема 4.3.1, стр. 224-227). Матричным уравнением Ляпунова называется уравнение вида $HA + A^*H = -C$, где $A$ — матрица системы $y' = Ay$, $C$ — заданная матрица, $H$ — искомая матрица (все размера $n \times n$). Это уравнение является частным случаем уравнения Сильвестра. Теорема Ляпунова устанавливает связь разрешимости этого уравнения с асимптотической устойчивостью: если для некоторой эрмитовой положительно определенной матрицы $C > 0$ существует решение $H$, которое является эрмитовой положительно определенной матрицей ($H = H^* > 0$), то нулевое решение системы $y' = Ay$ асимптотически устойчиво. Доказательство проводится двумя способами: 1) от противного, предполагая наличие собственного значения $\text{Re}\lambda \ge 0$ и приводя к противоречию с положительной определенностью $C$ и $H$; 2) через производную скалярного произведения $\langle Hy(t), y(t) \rangle$, которая оказывается равной $-\langle Cy(t), y(t) \rangle \le -\lambda_{\min}(C)\|y(t)\|^2$, откуда выводится экспоненциальное убывание нормы решения.

39. Неравенство Крейна для нормы матричной экспоненты.
**Ответ:** (Теорема 4.3.2, стр. 228). Неравенство Крейна дает оценку нормы матричной экспоненты $e^{tA}$ при $t \ge 0$ через свойства решения матричного уравнения Ляпунова. Если матрица $H = H^* > 0$ является решением уравнения $HA + A^*H = -I$ (где $I$ — единичная матрица), то для нормы матричной экспоненты справедлива оценка: $\|e^{tA}\|^2 \le e^{-t/\|H\|} \mu(H)$, при $t \ge 0$, где $\mu(H) = \|H\|\|H^{-1}\|$ — число обусловленности матрицы $H$ (отношение максимального собственного значения $H$ к минимальному). Вывод основан на оценке $\langle Hy(t), y(t) \rangle$, полученной при доказательстве теоремы Ляпунова для $C=I$: $\langle Hy(t), y(t) \rangle \le \exp\left(-t \frac{1}{\|H\|}\right) \langle Hy(0), y(0) \rangle$. Из этого неравенства с использованием свойств нормы эрмитовой положительно определенной матрицы выводится неравенство Крейна.

40. Матрица монодромии и мультипликаторы систем линейных дифференциальных уравнений с периодическими коэффициентами.
**Ответ:** (Определение 4.4.1, Теоремы 4.4.1-4.4.3, стр. 239-241). Рассматривается система $y' = A(t)y$, где $A(t+T) = A(t)$. Матрицей монодромии называется невырожденная постоянная матрица $B$, связывающая значения фундаментальной матрицы $Y(t)$ в моменты времени, отличающиеся на период $T$: $Y(t+T) \equiv Y(t)B$. Разные фундаментальные матрицы определяют подобные матрицы монодромии ($B_2 = S^{-1}B_1S$). Собственные значения матрицы монодромии называются мультипликаторами системы. Число $\mu$ является мультипликатором тогда и только тогда, когда существует нетривиальное решение системы, удовлетворяющее условию $y(t+T) = \mu y(t)$ для всех $t \ge 0$ (Теорема 4.4.3). Если $Y(t)$ — матрицант (т.е. $Y(0)=I$), то матрица монодромии $B = Y(T)$.
41. Теорема Флоке.
**Ответ:** (Теорема 4.4.4, стр. 241). Теорема Флоке утверждает, что если $Y(t)$ — фундаментальная матрица решений системы линейных дифференциальных уравнений с $T$-периодическими коэффициентами $y' = A(t)y$, то существуют невырожденная $T$-периодическая непрерывно дифференцируемая матрица $Q(t)$ и постоянная матрица $P$ такие, что справедливо тождество $Y(t) \equiv Q(t)e^{tP}$ при $t \ge 0$. При этом матрица $P$ может быть найдена как $P = \frac{1}{T}\ln B$, где $B$ — матрица монодромии, а $Q(t) = Y(t)e^{-tP}$.

42. Спектральный критерий устойчивости решений однородных систем линейных дифференциальных уравнений с периодическими коэффициентами.
**Ответ:** (Теорема 4.4.5, стр. 242-243). Нулевое решение системы с периодическими коэффициентами асимптотически устойчиво тогда и только тогда, когда все ее мультипликаторы $\mu_j$ (собственные значения матрицы монодромии) лежат строго внутри единичного круга: $|\mu_j| < 1$. Нулевое решение устойчиво по Ляпунову тогда и только тогда, когда для всех мультипликаторов выполнено $|\mu_j| \le 1$, причем мультипликаторам, лежащим на единичной окружности ($|\mu_k|=1$), соответствуют только одномерные жордановы клетки матрицы монодромии.

43. Разностное уравнение Ляпунова. Оценка нормы матрицанта систем линейных дифференциальных уравнений с периодическими коэффициентами.
**Ответ:** (Определение 4.4.3, Теорема 4.4.6, Следствие 4.4.2, стр. 243-245). Разностным (дискретным) уравнением Ляпунова называется матричное уравнение $H - B^*HB = C$, где $B$ — матрица монодромии, $C$ — заданная, $H$ — неизвестная матрицы. Нулевое решение системы асимптотически устойчиво тогда и только тогда, когда для любой эрмитовой положительно определенной матрицы $C = C^* > 0$ существует единственное эрмитово положительно определенное решение $H = H^* > 0$ разностного уравнения Ляпунова. При этом решение представимо в виде сходящегося матричного ряда $H = \sum_{k=0}^{\infty}(B^*)^k C B^k$.

44. Дифференциальное уравнение Ляпунова. Критерий устойчивости нулевого решения однородных систем линейных дифференциальных уравнений с периодическими коэффициентами.
**Ответ:** (Определение 4.4.4, Теорема 4.4.7, стр. 245-249). Матричным дифференциальным уравнением Ляпунова называется уравнение $\frac{d}{dt}H + HA(t) + A^*(t)H = -C(t)$. Критерий устойчивости формулируется в терминах разрешимости краевой задачи для этого уравнения с условием $H(0) = H(T)$. Нулевое решение системы асимптотически устойчиво тогда и только тогда, когда для любой непрерывной $T$-периодической матрицы $C(t) = C^*(t) > 0$ существует эрмитово положительно определенное $T$-периодическое решение $H(t) = H^*(t) > 0$ дифференциального уравнения Ляпунова.

45. Дифференциальное уравнение Ляпунова. Оценка нормы решений систем линейных дифференциальных уравнений с периодическими коэффициентами.
**Ответ:** (Теорема 4.4.8, стр. 250-252). Если нулевое решение асимптотически устойчиво, то существует $T$-периодическое эрмитово положительно определенное решение $H(t)$ дифференциального уравнения Ляпунова $\frac{d}{dt}H + HA(t) + A^*(t)H = -I$. В этом случае для нормы матрицанта $Y(t)$ справедлива оценка, являющаяся аналогом неравенства Крейна: $\|Y(t)\|^2 \le \frac{\|H(0)\|}{h_{\min}(t)} \exp\left(-\int_0^t \frac{1}{\|H(s)\|}ds\right)$ при $t \ge 0$, где $h_{\min}(t)$ — минимальное собственное число матрицы $H(t)$. Из этой оценки следует соответствующая оценка для любого решения задачи Коши.
46. Теорема об устойчивости по первому приближению для автономных систем.
**Ответ:** (Теорема 4.5.1, стр. 253). Рассматривается система $y' = Ay + \varphi(y)$, где $A$ — постоянная матрица (матрица Якоби в нуле), а $\varphi(y)$ удовлетворяет оценке $\|\varphi(y)\| \le q\|y\|^{1+\omega}$ ($\omega > 0$). Если все собственные значения матрицы $A$ лежат строго в левой полуплоскости ($\text{Re}\lambda_j < 0$), то нулевое решение исходной системы асимптотически устойчиво.

47. Теорема о неустойчивости по первому приближению для автономных систем.
**Ответ:** (Теорема 4.5.2, стр. 258). Для системы $y' = Ay + \varphi(y)$ с теми же условиями на $\varphi(y)$: если существует хотя бы одно собственное значение матрицы первого приближения $A$ со строго положительной вещественной частью ($\text{Re}\lambda_k > 0$), то нулевое решение системы неустойчиво.

48. Теорема Ляпунова об устойчивости решений автономных систем.
**Ответ:** (Теорема 4.5.3, стр. 263). Для автономной системы $y' = f(y)$. Если в окрестности нуля существует непрерывно дифференцируемая функция Ляпунова $H(y)$ такая, что: 1) $H(y) \ge 0$ и $H(y)=0 \iff y=0$; 2) производная функции в силу системы неположительна: $\langle \nabla H(y), f(y) \rangle \le 0$, то нулевое решение устойчиво по Ляпунову.

49. Теорема Ляпунова об асимптотической устойчивости решений автономных систем.
**Ответ:** (Теорема 4.5.4, стр. 264). Если в условиях предыдущей теоремы производная функции Ляпунова в силу системы строго отрицательна вне нуля: $\langle \nabla H(y), f(y) \rangle < 0$ при $0 < \|y\| < r$, то нулевое решение асимптотически устойчиво.

50. Теорема Ляпунова о неустойчивости решений автономных систем.
**Ответ:** (Теорема 4.5.6, стр. 267). Если для системы $y' = f(y)$ существует непрерывно дифференцируемая положительно определенная функция $H(y)$ ($H(y) \ge 0$, $H(y)=0 \iff y=0$), производная которой в силу системы строго положительна вне нуля: $\langle \nabla H(y), f(y) \rangle > 0$ при $0 < \|y\| < r$, то нулевое решение системы неустойчиво.
51. Теорема Четаева.
**Ответ:** (Теорема 4.5.5, стр. 266-267). Пусть существуют функция $H(y)$ и область $\Pi \subset B(0,r)$ такие, что: 1) $H(y) \in C^1(B(0,r))$; 2) $H(y) > 0$ для $y \in \Pi$, при этом $0 \notin \Pi$, $0 \in \partial\Pi$, $H(y)|_{y \in \partial\Pi} = 0$ при $\|y\| < r$. Если производная функции $H$ в силу системы строго положительна в этой области: $\langle \nabla H(y), f(y) \rangle > 0$ при $y \in \Pi$, то нулевое решение системы $y'=f(y)$ неустойчиво. Доказательство проводится от противного: предполагается устойчивость по Ляпунову, и показывается, что решение, начинающееся в области $\Pi$, должно ее покинуть, так как функция $H(y)$ растет вдоль решения, что приводит к противоречию с предполагаемой устойчивостью.

52. Первые интегралы систем обыкновенных дифференциальных уравнений.
**Ответ:** (Определение 5.1.1, Теорема 5.1.1, стр. 271-272). Функция $\Phi(t,y) \not\equiv \text{const}$, определенная в области $G$, называется первым интегралом системы $y'=f(t,y)$, если для любого решения $y(t)$ системы выполнено тождество $\Phi(t,y(t)) \equiv \text{const}$. Если функция гладкая ($\in C^1(G)$), то она является первым интегралом тогда и только тогда, когда она удовлетворяет дифференциальному уравнению с частными производными $\frac{\partial\Phi}{\partial t} + \sum_{j=1}^n f_j(t,y)\frac{\partial\Phi}{\partial y_j} = 0$ (т.е. ее полная производная по времени в силу системы равна нулю). Любая суперпозиция $F(\Phi(t,y))$ непрерывной функции $F$ и первого интеграла $\Phi$ также является первым интегралом.

53. Независимые первые интегралы.
**Ответ:** (Определение 5.1.2, стр. 275). Пусть $\Phi_1(t,y), \dots, \Phi_k(t,y)$ — первые интегралы системы в области $G$. Они называются независимыми в подобласти $G' \subset G$, если ранг матрицы Якоби, составленной из их частных производных по переменным $y_1, \dots, y_n$ (матрица размера $k \times n$), равен $k$ во всех точках этой подобласти $G'$. Число независимых первых интегралов системы $n$-го порядка не может превышать $n$. Знание $n$ независимых первых интегралов позволяет в неявном виде записать общее решение системы дифференциальных уравнений.

54. Однородные линейные дифференциальные уравнения с частными производными первого порядка. Задача Коши.
**Ответ:** (стр. 282-285). Однородное линейное уравнение имеет вид $f_0(t,y)u_t + \sum_{j=1}^n f_j(t,y)u_{y_j} = 0$. Задача Коши ставится как нахождение решения $u(t,y)$, удовлетворяющего начальному условию $u|_{t=t_0} = \varphi(y)$. Если в начальной точке $f_0(t_0, y^0) \neq 0$, то решение существует. Поиск решения эквивалентен нахождению $n$ независимых первых интегралов $\Phi_1, \dots, \Phi_n$ соответствующей системы обыкновенных дифференциальных уравнений. Тогда общее решение записывается как $u(t,y) = F(\Phi_1(t,y), \dots, \Phi_n(t,y))$, где $F$ — произвольная гладкая функция. Подставляя начальное условие $\varphi(y)$, можно однозначно определить вид функции $F$ и найти единственное решение задачи Коши.

55. Характеристики линейных дифференциальных уравнений с частными производными первого порядка.
**Ответ:** (Определение 5.2.2, Теорема 5.2.2, стр. 288-289). Для линейного уравнения в частных производных $f_0(t,y)u_t + \sum_{j=1}^n f_j(t,y)u_{y_j} = g(t,y)$ характеристической системой называется автономная система обыкновенных дифференциальных уравнений, задаваемая соотношениями: $\frac{dt}{ds} = f_0(t,y)$, $\frac{dy_j}{ds} = f_j(t,y)$ ($j=1,\dots,n$). Фазовые траектории этой системы в расширенном фазовом пространстве $\mathbb{R}^{n+1}$ переменных $(t, y_1, \dots, y_n)$ называются характеристиками (или характеристическими кривыми) исходного уравнения. Важное свойство: любое решение $u(t,y)$ однородного уравнения (где $g \equiv 0$) вдоль любой его характеристики сохраняет постоянное значение, то есть $u(t(s), y(s)) \equiv \text{const}$.
56. Неоднородные линейные дифференциальные уравнения с частными производными первого порядка. Задача Коши.
**Ответ:** (Теорема 5.2.4, стр. 291-294). Неоднородное уравнение имеет вид $f_0 u_t + \sum f_j u_{y_j} + \alpha u = g(t,y)$ с условием $u|_{t=t_0} = \varphi(y)$. Если $f_0(t_0, y^0) \neq 0$, то задача Коши локально однозначно разрешима. Решение ищется методом характеристик: вдоль характеристики $h$ (определяемой системой $dt/ds = f_0$, $dy_j/ds = f_j$) уравнение превращается в линейное ОДУ $d\tilde{u}/ds + \tilde{\alpha}(s)\tilde{u} = \tilde{g}(s)$. Интегрируя его с начальным условием, заданным на нехарактеристической поверхности $t=t_0$, получаем явную формулу для решения задачи Коши.

57. Квазилинейные дифференциальные уравнения с частными производными первого порядка.
**Ответ:** (Теоремы 5.3.1 и 5.3.2, стр. 301-305). Квазилинейное уравнение имеет вид $f_0(t,y,u)u_t + \sum f_j(t,y,u)u_{y_j} = g(t,y,u)$. Геометрический смысл: векторное поле $F = (f_0, f_1, \dots, f_n, g)$ в каждой точке решения касается его графика (поверхности $u = u(t,y)$), так как оно ортогонально нормали $(u_t, u_y, -1)$. Для решения составляется вспомогательное линейное однородное уравнение от большего числа переменных: $f_0 v_t + \sum f_j v_{y_j} + g v_u = 0$. Если функция $v(t,y,u)$ является решением этого уравнения и $v_u \neq 0$, то неявно заданная функция $v(t,y,u) = 0$ определяет решение исходного квазилинейного уравнения.

58. Задача Коши для квазилинейных дифференциальных уравнений с частными производными первого порядка.
**Ответ:** (Теорема 5.3.3, стр. 306-310). Задача Коши $u|_{t=t_0} = \varphi(y)$ для квазилинейного уравнения. Если $f_0(t_0, y^0, \varphi(y^0)) \neq 0$, задача локально однозначно разрешима. Алгоритм решения (3 этапа): 1) выписывается характеристическая система ОДУ $dy_j/dt = f_j/f_0$, $du/dt = g/f_0$; 2) находятся ее независимые первые интегралы (решения с начальными условиями $y_j^0, u^0$); 3) составляется функциональное уравнение $u^0(t,y,u) - \varphi(y_1^0(t,y,u), \dots, y_n^0(t,y,u)) = 0$, разрешение которого относительно $u$ дает искомое решение $u(t,y)$.

59. Задача Коши для уравнения Гамильтона-Якоби.
**Ответ:** (стр. 311-319). Рассматривается нелинейное уравнение первого порядка вида $u_t + H(t, y, u, u_{y_1}, \dots, u_{y_n}) = 0$ с начальным условием $u|_{t=t_0} = \varphi(y)$. Для решения применяется метод введения новых неизвестных функций $p_j = u_{y_j}$. Исходное уравнение дифференцируется по $y_j$, что позволяет свести задачу к системе квазилинейных уравнений для вектор-функции $v = (u, p_1, \dots, p_n)^T$: $v_t + \sum H_{p_j} v_{y_j} = g$. Начальные условия принимают вид $u|_{t=t_0} = \varphi(y)$ и $p_j|_{t=t_0} = \varphi_{y_j}(y)$. Найдя решение этой расширенной задачи Коши, его первая компонента $u(t,y)$ даст решение исходного нелинейного уравнения.
