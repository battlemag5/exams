**Задача 11.25**

Двумерное распределение пары целочисленных случайных величин $(\xi, \eta)$ задано таблицей $P\{\xi = i, \eta = j\}$:

| $\eta \backslash \xi$ | **-1** | **0** | **1** |
| --- | --- | --- | --- |
| **-1** | $1/8$ | $5/24$ | $1/6$ |
| **1** | $1/12$ | $7/24$ | $1/8$ |

Найти:

а) $E\xi$, $D\xi$;

б) $E\eta$, $D\eta$;

в) $Cov(\xi, \eta)$;

г) $E(\xi - 2\eta)$, $D(\xi - 2\eta)$.

**Решение:**

1. **Маргинальные распределения:**
* $\xi$:
* $P(\xi = -1) = \frac{1}{8} + \frac{1}{12} = \frac{5}{24}$
* $P(\xi = 0) = \frac{5}{24} + \frac{7}{24} = \frac{12}{24} = \frac{1}{2}$
* $P(\xi = 1) = \frac{1}{6} + \frac{1}{8} = \frac{7}{24}$


* $\eta$:
* $P(\eta = -1) = \frac{1}{8} + \frac{5}{24} + \frac{1}{6} = \frac{1}{2}$
* $P(\eta = 1) = \frac{1}{12} + \frac{7}{24} + \frac{1}{8} = \frac{1}{2}$




2. **Вычисления:**
* **а)**
$E\xi = -1 \cdot \frac{5}{24} + 0 \cdot \frac{1}{2} + 1 \cdot \frac{7}{24} = \mathbf{\frac{1}{12}}$
$E(\xi^2) = (-1)^2 \cdot \frac{5}{24} + 0^2 \cdot \frac{1}{2} + 1^2 \cdot \frac{7}{24} = \frac{12}{24} = \frac{1}{2}$ *(в рукописи ошибочно указано $\frac{3}{4}$)*
$D\xi = E(\xi^2) - (E\xi)^2 = \frac{1}{2} - \left(\frac{1}{12}\right)^2 = \mathbf{\frac{71}{144}}$ *(в рукописи ошибочно $\frac{107}{144}$)*
* **б)**
$E\eta = -1 \cdot \frac{1}{2} + 1 \cdot \frac{1}{2} = \mathbf{0}$
$E(\eta^2) = (-1)^2 \cdot \frac{1}{2} + 1^2 \cdot \frac{1}{2} = 1$
$D\eta = E(\eta^2) - (E\eta)^2 = \mathbf{1}$
* **в)**
$E(\xi\eta) = (-1)(-1)\frac{1}{8} + (1)(-1)\frac{1}{6} + (-1)(1)\frac{1}{12} + (1)(1)\frac{1}{8} = \frac{1}{4} - \frac{1}{4} = 0$ *(в рукописи ошибочно $\frac{1}{4}$)*
$Cov(\xi, \eta) = E(\xi\eta) - E\xi E\eta = 0 - \frac{1}{12} \cdot 0 = \mathbf{0}$
* **г)**
$E(\xi - 2\eta) = E\xi - 2E\eta = \mathbf{\frac{1}{12}}$
$D(\xi - 2\eta) = D\xi + 4D\eta - 4 Cov(\xi, \eta) = \frac{71}{144} + 4 \cdot 1 - 0 = \mathbf{\frac{647}{144}}$

**Задача 11.62**

Пусть $\xi_1, \xi_2, \dots, \xi_{n+1}$ — независимые случайные величины, принимающие значения $1$ и $0$ с вероятностями $p$ и $1-p$ соответственно. Найти среднее значение и дисперсию суммы $\zeta = \eta_1 + \dots + \eta_n$, где $\eta_i = \xi_i \xi_{i+1}$.

**Решение:**

1. **Математическое ожидание компонентов:**
* $E\eta_i = E(\xi_i \xi_{i+1}) = p^2$
* $E\zeta = E(\eta_1 + \dots + \eta_n) = n E\eta_1 = \mathbf{n p^2}$


2. **Дисперсия и вторые моменты:**
* $E(\eta_i^2) = E(\xi_i^2 \xi_{i+1}^2) = p^2$
* $E(\eta_i \eta_{i+1}) = E(\xi_i \xi_{i+1}^2 \xi_{i+2}) = p^3$
* $E(\eta_i \eta_j) = E(\xi_i \xi_{i+1} \xi_j \xi_{j+1}) = p^4$, при $\vert{}i - j\vert{} \ge 2$


3. **Расчет $E(\zeta^2)$ и $D\zeta$:**

$$E(\zeta^2) = n p^2 + 2(n-1)p^3 + (n-1)(n-2)p^4$$


$$D\zeta = E(\zeta^2) - (E\zeta)^2 = n p^2 + 2(n-1)p^3 + (n-1)(n-2)p^4 - n^2 p^4$$


$$D\zeta = \mathbf{n p^2 + 2(n-1)p^3 + (2 - 3n)p^4}$$

**Задача 11.69**

Найти коэффициент корреляции между $\xi$ и $\xi^2$, и определить, являются ли они независимыми:
а) $P\{\xi = 0\} = 1/3, P\{\xi = 1\} = 1/2, P\{\xi = -1\} = 1/6$;

б) $P\{\xi = -2\} = P\{\xi = -1\} = P\{\xi = 1\} = P\{\xi = 2\} = 1/4$.

**Решение:**

* **Пункт а):**
* $E\xi = -1 \cdot \frac{1}{6} + 0 \cdot \frac{1}{3} + 1 \cdot \frac{1}{2} = \frac{1}{3}$
* $E(\xi^2) = E(\xi^4) = (-1)^2 \cdot \frac{1}{6} + 0 \cdot \frac{1}{3} + 1^2 \cdot \frac{1}{2} = \frac{2}{3}$
* $E(\xi^3) = (-1)^3 \cdot \frac{1}{6} + 0 + 1^3 \cdot \frac{1}{2} = \frac{1}{3}$
* $Cov(\xi, \xi^2) = E(\xi^3) - E\xi E(\xi^2) = \frac{1}{3} - \frac{1}{3} \cdot \frac{2}{3} = \frac{1}{9}$
* $D\xi = \frac{2}{3} - \left(\frac{1}{3}\right)^2 = \frac{5}{9}$, $D(\xi^2) = \frac{2}{3} - \left(\frac{2}{3}\right)^2 = \frac{2}{9}$
* $\rho(\xi, \xi^2) = \frac{1/9}{\sqrt{5/9 \cdot 2/9}} = \mathbf{\frac{1}{\sqrt{10}}}$
* Так как $\rho(\xi, \xi^2) \neq 0$, случайные величины **зависимы**.


* **Пункт б):**
* В силу симметрии распределения: $E\xi = 0$, $E(\xi^3) = 0$.
* $Cov(\xi, \xi^2) = E(\xi^3) - E\xi E(\xi^2) = 0 \Rightarrow \mathbf{\rho(\xi, \xi^2) = 0}$.
* Проверка независимости:
* $P\{\xi = 1, \xi^2 = 1\} = P\{\xi = 1\} = \frac{1}{4}$
* $P\{\xi = 1\} \cdot P\{\xi^2 = 1\} = \frac{1}{4} \cdot \left(\frac{1}{4} + \frac{1}{4}\right) = \frac{1}{8}$
* Поскольку $\frac{1}{4} \neq \frac{1}{8}$, величины **зависимы** (несмотря на нулевую корреляцию).

**Задача 11.23**

Случайные величины $\xi, \eta, \zeta$ независимы и имеют стандартное нормальное распределение $N(0, 1)$. Найти среднее значение и дисперсию случайной величины $X = \xi + \xi\eta + \xi\eta\zeta$.

**Решение:**

1. **Математическое ожидание:**

$$EX = E\xi + E(\xi\eta) + E(\xi\eta\zeta) = E\xi + E\xi E\eta + E\xi E\eta E\zeta = 0 + 0 + 0 = \mathbf{0}$$


2. **Дисперсия:**
Поскольку $E\xi = E\eta = E\zeta = 0$ и $E(\xi^2) = E(\eta^2) = E(\zeta^2) = 1$, все попарные ковариации слагаемых равны нулю:
* $Cov(\xi, \xi\eta) = E(\xi^2\eta) = E(\xi^2)E\eta = 0$
* $Cov(\xi, \xi\eta\zeta) = E(\xi^2\eta\zeta) = 0$
* $Cov(\xi\eta, \xi\eta\zeta) = E(\xi^2\eta^2\zeta) = E(\xi^2)E(\eta^2)E\zeta = 0$


Дисперсия суммы равна сумме дисперсий:
* $D\xi = 1$
* $D(\xi\eta) = E(\xi^2\eta^2) - (E(\xi\eta))^2 = 1 \cdot 1 - 0 = 1$
* $D(\xi\eta\zeta) = E(\xi^2\eta^2\zeta^2) - (E(\xi\eta\zeta))^2 = 1 \cdot 1 \cdot 1 - 0 = 1$


$$DX = D\xi + D(\xi\eta) + D(\xi\eta\zeta) = 1 + 1 + 1 = \mathbf{3}$$
